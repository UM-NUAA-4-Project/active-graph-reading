## 九、条件化图阅读（Contingent Graph Reading）：Submit-Early 提前提交

Section 7 架构中，Reader 在预算用尽后必须上交子图分类——无论信念是否足够确定。本章解除这一约束，赋予 Reader 在信念足够确定时**提前终止**的能力。核心理念：预算从"定额"变为"上限"。

### 9.1 动机

固定预算 $B$ 对所有图一视同仁，但不同图的信息密度不同：

- 信息密度高的图（关键结构被 seed 覆盖）→ 几步后信念已确定 → 剩余预算浪费
- 信息密度低的图（seed 远离关键结构）→ $B$ 步后信念仍高度不确定 → 强行分类 = 高风险

**方案**：给 Reader 自主 SUBMIT 权——信念已确定时提前提交分类，不必耗满预算。这是纯粹的"提前交卷"：可以在预算内任意时刻终止，但**不能**超出 $B$。

**设计裁剪（v5 vs v4）**：原 v4 设计包含 SUBMIT + CONTINUE + FORGET 三种扩展动作。经实验数据审视裁剪——

| 动作 | 决定 | 理由 |
|------|:---:|------|
| SUBMIT | ✅ 保留 | 直接应对"信息密度不同"的核心痛点 |
| CONTINUE | ❌ 移除 | 要额外预算有悖"预算约束下最优"的核心目标 |
| FORGET | ❌ 移除 | seed 质量对 reader 影响极小（best vs worst seed ~1 pp）；FORGET 净成本 3:1 不划算；去掉避免引入逆行转移复杂度 |

### 9.2 扩展 POMDP 元组

$$
\text{POMDP}_{\text{SE}} = (S, A_{\text{ext}}, O, T, \Omega, R, B)
$$

| POMDP 元素 | 原始定义 | 扩展定义 | 变更性质 |
| ---------- | -------- | -------- | -------- |
| $A$ | $\{\text{reveal\_node}(v)\}$ | $A \cup \{\text{SUBMIT}\}$（$t \geq k$ 可用） | **新增一种动作** |
| 时域 $H$ | $B$（固定） | 实际步数 $\in [k, B]$ | **可变时域** |
| 终止条件 | $t = B$ | $t = B$ or SUBMIT（两者之一） | **新增终止路径** |

转移模型、观测模型、奖励函数不变。SUBMIT 为终端动作（不可逆），执行后立即分类。

### 9.3 三步架构

```
t ∈ [1, k-1]:   预热期 — 禁止 SUBMIT，只 reveal（k = ⌈B/2⌉）
t ∈ [k, B-1]:   决策期 — SubmitHead 每步判断 → SUBMIT or reveal
t = B:          强制期 — 未 SUBMIT 则强制分类（同当前）
```

预热期确保 reader 至少探索了图的一半预算后再做提交决策。

### 9.4 SubmitHead 设计

提交决策头，挂载在共享 POMDP 组件上，与 ReaderHead 并行：

```
输入:  [H(b_t), u_t, t/B]    # 信念熵, 不确定度, 进度比
结构:  Linear(3→16)→ReLU→Linear(16→1)→Sigmoid
输出:  p_submit ∈ [0,1]
参数:  ~300
```

- $H(b_t)$ 低 → 信念尖峰 → $p_{\text{submit}}$ 高
- $u_t$ 高 → 不确定 → $p_{\text{submit}}$ 低
- $t/B$ 高 → 快上限 → $p_{\text{submit}}$ 高

SubmitHead 和 ReaderHead 共享信念流，独立决策、独立 loss、统一 backward。

### 9.5 决策策略

$$
\pi_\theta(a_t \mid s_t) = 
\begin{cases}
\pi_\theta^{\text{reader}}(a_t \mid s_t) & t < k \\[6pt]
p_{\text{submit}} \cdot \text{SUBMIT} + (1-p_{\text{submit}}) \cdot \pi_\theta^{\text{reader}}(a_t \mid s_t) & t \geq k
\end{cases}
$$

推理时用阈值判定 $a_{\text{submit}} = \mathbf{1}[p_{\text{submit}} > \tau]$，$\tau$ 默认为 0.5（可调）。训练时用 Bernoulli 采样保留探索。

### 9.6 训练策略

**反事实标签**（解决 SubmitHead ~300 参数冷启动）：

对每步 $t \geq k$，用当前子图跑一次冻结 classifier 预测 → $y_{\text{submit},t} = \mathbf{1}[\text{pred} == y]$。标签无噪声、每步一个 → 信号密集 → SubmitHead 10-20 步收敛。

**联合训练 loss**：

$$
\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{reader}} + \lambda \cdot \mathcal{L}_{\text{submit}}
$$

$$
\mathcal{L}_{\text{submit}} = -\frac{1}{B-k+1} \sum_{t=k}^{B} [y_{\text{submit},t} \log p_{\text{submit},t} + (1-y_{\text{submit},t}) \log(1-p_{\text{submit},t})]
$$

| 阶段 | 内容 | SubmitHead | Reader | 共享层 |
|------|------|:----------:|:------:|:------:|
| Phase 2.5 | 反事实预训练 | 训练 | 冻结 | 冻结 |
| Phase 3 | 联合 RL | 训练 | 训练 | 微调 |

$\lambda$ 默认 1.0。

### 9.7 信息流

```
步骤 t:

  t < k (预热):                       t ≥ k (决策):
  ┌────────────────────┐              ┌────────────────────────────┐
  │ 标准循环            │              │                            │
  │ 证据通道 → e_t       │              │ SubmitHead(b_t, u_t, t/B)   │
  │ LSTM → b_t, u_t    │              │   → p_submit               │
  │ reader → reveal    │              │   │                         │
  │ 更新 state → 下一步  │              │   ├── p > τ: SUBMIT        │
  └────────────────────┘              │   │    子图→分类→ŷ→结束     │
                                      │   │                         │
                                      │   └── p ≤ τ: reader→reveal  │
                                      │        更新 state → 下一步   │
                                      └────────────────────────────┘
```

### 9.8 改动范围

| 组件 | 改动 | 程度 |
|------|------|:----:|
| `pomdp_reader.py` | 新增 `SubmitHead` 模块 | 小 |
| `graph_state.py` | \(\emptyset\)（无 FORGET → 不需要遗忘机制） | — |
| `reveal_action.py` | \(\emptyset\) | — |
| 训练脚本 | 新增 `train_phase25_submit.py`（Phase 2.5 反事实预训练） | 新 |

| eval 脚本 | 修改 `pomdp/eval.py`（`--enable-submit` 开关 + $\tau$ 参数） | 小 |

### 9.9 关键洞察

1. **元认知**：SubmitHead 是 Reader 对自身认知状态的认知。$b_t$ 说"我相信这个类是 k"，$u_t$ 说"我对这个判断有多不确定"，SubmitHead 说"基于这两者，我该上交了吗"
2. **自适应预算**：信息密度高的图提前 SUBMIT（实际步数 $< B$），信息密度低的图耗满 $B$ 步强制分类。本质是对每张图执行自适应计算——类似 Early-Exit GNN 中不同样本经不同深度
3. **最小复杂度增量**：去掉 FORGET 后，整个扩展仅新增 ~300 参数和 1 个训练阶段。GraphState / reveal_action 完全不动，改动范围从原 v4 的 6 个文件缩减到 3 个
4. **反事实监督**：SubmitHead 的训练信号来自反事实分类——不是事后诸葛亮，而是"如果此时提交会怎样"的密集反馈，使 ~300 参数在极短时间内收敛
5. **经济性**：与 FORGET（3 budget 换 1 好节点）不同，SUBMIT 零成本——提前提交不消耗额外预算，省下的预算直接变为效率收益

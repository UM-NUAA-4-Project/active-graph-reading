# cifar10 主结果 reader 选点行为分析（预算 10%）

**一句话结论**：主结果 reader（evidence，RL 训练）唯一真偏好是**高前沿度数节点**（偏好转弱随进度衰减）；它**不追梯度归因**，与**信息增益**的关系随读入进度从弱跟随单调转为回避；读对与读错的图行为无差异。

## 数据与口径

| 项 | 值 |
|---|---|
| checkpoint | `checkpoint_epoch3.pt`（ev-R-read/evidence/rl，主结果） |
| 数据 / 协议 | CIFAR10 test 全量 10,000 图；B=10%·n；确定性 argmax rollout（与 eval 严格同款） |
| 样本量 | 113,007 步选择（单种子 s0）；无 teleport |
| 终判一致性 | ev_acc = 0.299 = eval_learnable.json s0（0.2994）✔ |

**指标**（每步被选中的前沿节点）："排名分位" = 该节点的教师分数在前沿候选内的名次占比（1=选了排名最靠前的候选，0.5=随机；度数为离散值，并列取中间名次）。随机基线：排名 0.5；选中最优率=1/|frontier|（均值 23.5 → ≈4.3%）。

## 四条核心规律

**1. 不追梯度归因** —— 排名分位 **0.504** [0.502, 0.506]，选中最优率 5.27%（基线 5.03%）。选点与归因排名统计独立。

**2. 与信息增益的关系随步数单调漂移** —— IG 排名从第 2 步 **0.573** 一路降到 ≥11 步 **0.452**，在第 5 步附近穿过 0.5：
- 早读（第 2–4 步）弱偏好"降熵"节点；
- 晚读（≥6 步）系统性**回避**降熵节点（所选节点 IG 均值同期 +0.027 → −0.017）。

**3. 前沿度数是唯一真偏好，且锁定"度数=2"** —— 排名分位 **0.620** [0.619, 0.622]，21.2% 的步骤选中度数并列最高的候选。逐步看更尖锐：第 2 步 **98.3%** 选度数=2 的节点，此后全程稳定在 **85–91%**（排名分位降至 ~0.53 是并列构成假象——候选池里度数 2 越来越多，mid-rank 在大同分群趋向 0.5，偏好本身不衰减）。
在近平面铺排的图上，度数 2 = 与已揭示区恰有两点连接的"边界凹角"：reader 永远在凹角向内补，让已揭示区紧致生长（圆盘式），而非拉出细长路径——纯靠 RL 收敛到的几何策略，与分类器信号无关。早期（q0）排名 0.712 是候选池度数尚低所致。

**4. 终判正误两组行为无差** —— 读对（n=2,990 图）grad/IG/度数排名 0.506/0.494/0.622，读错（n=7,010）0.504/0.495/0.620。分类成败不取决于是否挑中"信息量大的节点"。

## 怎么读图（choice_behavior_b10.pdf，183mm 双栏）

- **a**：三根柱 = 被选节点的平均排名分位，虚线=随机 0.5。柱子贴线=不看该信号（梯度、IG），过线=真偏好（度数 0.62）。
- **b**：被选（绿）vs 可选（灰）的平均前沿度数，横轴=逐步（1–10 步逐步，≥11 合并）。绿线第 2 步跳起=立刻挑高度数；第 6–7 步交叉=后期不再偏连接。
- **c**：IG 排名逐步单线，0.5 虚线。单调下行 = 从弱跟随到回避。
- **d**：读对（实心蓝）vs 读错（空心灰）的同一柱状，成对等高 = 行为与结果无关。

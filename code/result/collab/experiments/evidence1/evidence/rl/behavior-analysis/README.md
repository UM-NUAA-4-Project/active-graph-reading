# COLLAB 主结果 reader 选点行为分析（预算 10%，checkpoint_epoch6）

**一句话结论**：COLLAB 主结果 reader 是一个**近乎纯粹的"度数贪心"读者**——100% 的步骤选中前沿中度数并列最高的候选（排名 0.681，被选均值 5.88 vs 可选 4.32）；同时**系统性回避高信息增益节点**（排名 0.308，全程低于随机线）；对梯度归因只有弱跟随（0.558）；读错的图回避 IG 更少。

## 数据与口径

| 项 | 值 |
|---|---|
| checkpoint | `checkpoint_epoch6.pt`（collab/evidence1/evidence/rl） |
| 数据 / 协议 | COLLAB test 全量 501 图；B=10%·n（均值 7.3 步）；确定性 argmax rollout（与 eval 严格同款） |
| 样本量 | 3,257 步选择（单种子 s0）；无 teleport |
| 终判一致性 | ev_acc = 0.519 = eval_learnable.json test mean B10（0.519）✔ |
| 分类器参照 | 冻结分类器对最终揭示子图判定 0.158（少数类水平，既有 collab 口径） |

排名分位统一用中间名次（并列各取半份额）——COLLAB 上大量候选 IG 恰好并列（熵不变），strict 名次会失真；连续分数下两者数值相同。随机基线：排名 0.5。

## 四条核心规律（与 cifar10 对照）

**1. 前沿度数 = 主导信号，且是"贪心到顶"** —— 度数排名 **0.681** [0.661, 0.701]，**100% 的步骤选中度数并列最高的候选**（cifar10 仅 21%）。被选均值 5.88 vs 可选均值 4.32；逐步看被选曲线始终压着可选曲线（无 cifar10 的后期交叉）。第 1 步例外（种子邻居度数全为 1，没得挑）。

**2. 系统性回避高信息增益节点** —— IG 排名 **0.308** [0.286, 0.332]，远低于 0.5；逐步从第 2 步 0.35 滑到第 10 步 0.215，所选节点 IG 均值为负（−0.020）。reader 不是在找"最能纠正分类器"的节点。（≥11 桶回升到 0.401，为小样本尾部、图更大，见 b/c 图末点。）

**3. 梯度归因弱跟随** —— 排名 0.558 [0.543, 0.573]，显著但弱；cifar10 上完全不跟（0.504）。

**4. 读错 vs 读对行为有差** —— 读对（n=260）IG 排名 **0.245**，读错（n=241）**0.360**：读对的图回避 IG 更彻底；度数偏好读对组也更强（0.712 vs 0.654）。与 cifar10 的"正误无差"不同，COLLAB 上选点行为与终判结果相关。

**与 cifar10 的对照**：cifar10 = 只挑高度数、不看任何教师信号、正误无差；COLLAB = 高度数贪心 + 回避 IG + 弱跟梯度 + 正误有差。两个数据集上梯度/IG 都不是主导信号，度数才是共同偏好。

## 怎么读图（choice_behavior_b10.pdf，183mm 双栏）

- **a**：三根柱 = 被选节点平均排名分位，虚线=随机 0.5。度数柱（0.68）远超虚线，IG 柱（0.31）远低于虚线。
- **b**：被选（绿）vs 可选（灰）平均前沿度数，逐步（1–10 步 + ≥11 汇总）。绿线全程压住灰线 = 挑的节点连接更多。
- **c**：IG 排名逐步单线，0.5 虚线。整条线在虚线下方 = 回避降熵节点；≥11 桶上翘是小样本尾部。
- **d**：读对（实心蓝）vs 读错（空心灰）。IG 组两柱错开 = 回避强度与终判相关。

## 综述：图可解释性 vs 预算约束图阅读

### 范式对比

图可解释性回答"模型为什么做出这个预测"，与本项目"预算内揭示什么证据来做预测"在**目标**上高度一致——都是找关键子图。但在**时序**和**前提**上有根本差异：

| 维度 | 图可解释性 | 本项目（Budgeted Graph Reading） |
|------|----------|-------------------------------|
| **时序** | 事后（post-hoc）——先有预测，再找解释 | 事前（pre-hoc）——先逐步揭示，再做预测 |
| **图可见性** | 完整图 G 始终可见 | G₀ = (V, ∅, ∅)，逐步揭示 |
| **目标** | 解释已有模型的行为（找到关键子图） | 在预算内找到关键证据来做出最优预测 |
| **谁使用** | 人类分析师理解模型 | 模型自己做决策 |
| **核心问题** | "模型看了图的哪部分做出的预测？" | "在看不到全景时，先看哪部分才能做对预测？" |

### 关键差异

```
事后可解释性（GNNExplainer 等）：
    完整图 G → 训练好的 GNN → 预测 ŷ → 解释器 → 关键子图 S
    类比：老师改完卷子后，圈出"这道题的关键步骤"

    优势：已知答案，可以精确反推什么信息是充分的
    局限：需要完整图（本项目做不到）

本项目（Budgeted Graph Reading）：
    G₀ 几乎为空 → 策略选动作 → 揭示信息 → 累积观测 → 分类
    类比：侦探不看案卷，一步步收集线索，自己判断该看什么

    优势：更贴合真实"不知全貌"的场景
    挑战：没有全图作为 ground truth，决策困难
```

> **核心启示**：可解释性方法定义的"关键子图"是项目中 **oracle 策略**（最优揭示目标）的理论上界——如果我们知道完整图，GNNExplainer 给出的解释就是"最值得关注的证据"。项目的增量在于：在看不到完整图的情况下，能否通过顺序决策逼近这个上界。

### 论文 1：GNNExplainer（神经信息处理系统进展 2019, CCF-A）

| 维度 | 内容 |
|------|------|
| **论文名称** | GNNExplainer: Generating Explanations for Graph Neural Networks |
| **作者** | Rex Ying, Dylan Bourgeois, Jiaxuan You, Marinka Zitnik, Jure Leskovec |
| **发表** | **NeurIPS 2019** |
| **期刊等级** | **CCF-A**（人工智能顶级会议） |
| **arXiv** | [1903.03894](https://arxiv.org/abs/1903.03894) |

#### 摘要

GNN 通过在图边递归传递神经消息来结合节点特征和图结构，是图机器学习的有力工具。然而，结合结构和特征导致模型复杂，解释 GNN 预测仍未被解决。本文提出 GNNExplainer——首个通用的、模型无关的方法，为任何基于 GNN 的模型在任何图机器学习任务上提供可解释的解释。给定一个实例，GNNExplainer 识别一个紧凑的子图结构和一小部分节点特征，这些对 GNN 的预测至关重要。进一步地，GNNExplainer 可以为整个类别的实例生成一致简洁的解释。实验表明该方法能识别重要的图结构和节点特征，平均超越基线 17.1%。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 缺乏通用的、模型无关的 GNN 预测解释方法 |
| **核心贡献** | 首个通用 GNN 解释器——通过**最大化预测与子图分布之间的互信息**来搜索最优解释子图 |

#### 核心思路

```
GNNExplainer 优化目标：
    给定训练好的 GNN 模型 Φ 和输入图 G_c
    
    寻找子图 G_S（边掩码 + 特征掩码）：
    max MI(Y, G_S) = H(Y) - H(Y | G = G_S, X = X_S ⊙ σ(M))
    
    其中：
    - 边掩码：每条边被保留的概率
    - 特征掩码：每个特征维度被保留的概率
    
    优化方法：梯度下降搜索最优掩码
```

#### 与本项目的对比分析

##### 相似之处

| 维度 | GNNExplainer | 本项目 |
|------|-------------|--------|
| **关键子图** | 搜索对预测最重要的子图 | 揭示对分类最重要的证据 |
| **紧凑性** | 追求紧凑解释（掩码稀疏） | 预算约束天然保证揭示量有限 |
| **信息论** | 最大化 MI(预测, 子图) | 可借鉴 MI 作为揭示价值函数 |

##### 关键差异

| 维度 | GNNExplainer | 本项目 |
|------|-------------|--------|
| **时序** | 事后——先有全图 + 已有预测，再找解释 | 事前——逐步揭示，最后才做预测——根本差异 |
| **图可见性** | 完整图 G 始终可见 | G₀ = (V, ∅, ∅)，逐步揭示 |
| **优化方式** | 逐实例梯度优化（每个样本独立优化） | 策略学习——共享策略泛化到新图 |
| **输出** | 解释子图（给人看） | 观测子图（给分类器用） |
| **作用** | 理解模型行为 | 实现模型预测 |

> **启示**：GNNExplainer 的"最优解释子图"定义了我们对**oracle 揭示策略**的期望上界——如果能看到全图，最优揭示结果应该等于 GNNExplainer 找到的解释子图。项目目标是：在看不到全图时，通过策略逼近这个上界。

### 论文 2：PGExplainer（神经信息处理系统进展 2020, CCF-A）

| 维度 | 内容 |
|------|------|
| **论文名称** | Parameterized Explainer for Graph Neural Network |
| **作者** | Dongsheng Luo, Wei Cheng, Dongkuan Xu, Wenchao Yu, Bo Zong, Haifeng Chen, Xiang Zhang |
| **发表** | **NeurIPS 2020** |
| **期刊等级** | **CCF-A**（人工智能顶级会议） |
| **arXiv** | [2011.04573](https://arxiv.org/abs/2011.04573) |

#### 摘要

尽管 GNN 取得进展，解释 GNN 预测仍是挑战性开放问题。领先方法独立处理局部解释（重要子图结构和节点特征），即解释为何 GNN 对单个实例做出预测。然而，由于为每个实例从头训练一个解释器，这类方法对于大量实例是耗时的。此外，为单个实例生成的解释无法泛化到其他实例。本文提出 PGExplainer——一种参数化的 GNN 解释器。PGExplainer 学习一个全局的理解，通过集体解释多个实例来识别重要特征。其参数化特性使得可以自然解释未见实例而无需重新训练。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | GNNExplainer 为每个实例独立优化——耗时长、不可泛化 |
| **核心贡献** | 首个**参数化/可泛化**的 GNN 解释器——学习共享的边选择网络，对新实例前向推理即可 |

#### 核心思路

```
PGExplainer 训练：
    输入：图 G + 训练好的 GNN
    前向：边选择网络 → 每条边的"重要性"概率
    采样：Gumbel-Softmax → 离散边掩码 → 解释子图
    损失：解释子图在 GNN 下的预测一致性 + 稀疏性正则
    
推理：
    新图 → 前向推理 → 直接输出解释子图（无需优化）
```

#### 与本项目的对比分析

##### 相似之处

| 维度 | PGExplainer | 本项目 |
|------|------------|--------|
| **共享策略** | 学习全局边选择网络（归纳式） | 学习共享揭示策略 π（在多个图上训练） |
| **快速推理** | 新实例前向推理 → 直接得解释 | 新图前向推理 → 直接得揭示动作序列 |
| **可微采样** | Gumbel-Softmax 采样边 | 可借鉴 Gumbel-Softmax 采样揭示动作 |

##### 关键差异

| 维度 | PGExplainer | 本项目 |
|------|------------|--------|
| **时序** | 事后——完整图已知时做解释 | 事前——逐步揭示后做预测——根本差异 |
| **图可见性** | 完整图可见 | 逐步揭示 |
| **选择目标** | 选哪些边对"已有预测"最相关 | 选哪些节点/边对"未来预测"最有用 |
| **训练信号** | 预测一致性（解释后预测不变） | 最终分类精度（揭示后分类正确） |
| **预算** | 稀疏正则（软约束） | 显式预算 B（硬约束） |

> **启示**：PGExplainer 的**参数化边选择网络**在架构上与我们 M4/M5 阶段需要学习的策略网络高度相似——输入图（或观测图），输出每条边/每个节点的"被揭示概率"。其 Gumbel-Softmax + 预测一致性损失可直接转化为揭示策略的训练框架。

### 论文 3：SubgraphX（国际机器学习大会 2021, CCF-A）

| 维度 | 内容 |
|------|------|
| **论文名称** | On Explainability of Graph Neural Networks via Subgraph Explorations |
| **作者** | Hao Yuan, Haiyang Yu, Jie Wang, Kang Li, Shuiwang Ji |
| **发表** | **ICML 2021**（Spotlight） |
| **期刊等级** | **CCF-A**（机器学习顶级会议） |
| **代码** | [github.com/divelab/DIG](https://github.com/divelab/DIG) |

#### 摘要

尽管 GNN 取得了令人振奋的进展，在关键决策应用中使用 GNN 需要可解释性。现有工作主要关注对 GNN 预测的事后解释，通过识别对预测重要的关键子图。然而，大多数方法基于梯度或注意力识别重要节点/边——这些归因方法往往无法有效捕获子图的联合效应。本文提出 SubgraphX——通过**蒙特卡洛树搜索（MCTS）**高效探索不同子图，并使用**Shapley 值**度量子图重要性。SubgraphX 提供了更可解释的子图级解释，并能自然地处理图分类和节点分类任务。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 节点/边级归因无法捕获子图的**组合效应**（cooperative effect）——一条边可能单独不重要，但与其他边组合很关键 |
| **核心贡献** | 首次将 **MCTS + Shapley 值**引入 GNN 解释——通过树搜索探索子图空间，Shapley 值公平度量子图贡献 |

#### 核心思路

```
MCTS 子图探索：
    根节点 = 完整图
    每步动作 = 剪枝一个节点（缩小解释子图）
    
    选择（Selection）：UCB 平衡探索与利用
    扩展（Expansion）：随机采样未探索的剪枝动作
    模拟（Simulation）：随机剪枝到终止 → 得到候选子图
    回传（Backpropagation）：更新路径上节点的 Shapley 值估计

Shapley 值度量子图重要性：
    φ(S) = Σ_{T⊆V\S}  |T|!(|V|-|T|-|S|)! / |V|! · [f(S∪T) - f(T)]
    衡量子图 S 在所有可能的组合中对预测的边际贡献
```

#### 与本项目的对比分析

##### 相似之处

| 维度 | SubgraphX | 本项目 |
|------|-----------|--------|
| **顺序探索** | MCTS 顺序剪枝（逐步缩小解释子图） | 顺序揭示（逐步扩大观测子图） |
| **组合决策** | 考虑节点/边的联合效应（Shapley 值） | 揭示动作间有依赖（后步受前步影响） |
| **探索-利用** | UCB 平衡探索与利用 | 策略需要平衡信息获取与预算消耗 |

##### 关键差异

| 维度 | SubgraphX | 本项目 |
|------|-----------|--------|
| **时序** | 事后——从全图出发剪枝（收缩方向） | 事前——从空图出发揭示（扩张方向）——根本差异 |
| **方向** | 剪枝：全图 → 子图（coarse-to-fine） | 揭示：空图 → 子图（fine-to-coarse） |
| **图可见性** | 完整图 G 始终可见 | 逐步揭示 |
| **搜索算法** | MCTS（离线树搜索） | 策略网络（在线单步选择） |
| **评价指标** | Shapley 值（公平性） | 信息增益/分类精度（效率） |

> **启示**：SubgraphX 的 MCTS + Shapley 值框架天然适配项目——如果将方向反转（扩张而非剪枝），MCTS 可用来**规划揭示顺序**：从 G₀ 出发，每步选择一个揭示动作，用 Shapley 值评估该动作对未来分类的边际贡献。这在理论上是最优的 oracle 揭示策略。

### 论文 4：ReFine（神经信息处理系统进展 2021, CCF-A）

| 维度 | 内容 |
|------|------|
| **论文名称** | Towards Multi-Grained Explainability for Graph Neural Networks |
| **作者** | Xiang Wang, Yingxin Wu, An Zhang, Xiangnan He, Tat-Seng Chua |
| **发表** | **NeurIPS 2021** |
| **期刊等级** | **CCF-A**（人工智能顶级会议） |

#### 摘要

当 GNN 做出预测时，现有工作主要生成粗粒度的子图级解释或细粒度的节点/边级归因。然而，具备多粒度可解释性的高性能范式目前仍缺失。本文利用预训练和微调的思想开发 ReFine——首先生成多粒度的基础解释（粗粒度的子图 + 细粒度的边），然后通过类感知正则化对解释进行微调，使其对不同类别更具区分性。实验验证了 ReFine 在多粒度解释质量和分类性能上的优势。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 现有解释方法只提供单一粒度（子图 or 边），缺乏多粒度解释 |
| **核心贡献** | 首个多粒度 GNN 解释框架——粗粒度子图 + 细粒度边 + 类感知微调 |

#### 核心思路

```
预训练阶段（生成基础解释）：
    ├─ 粗粒度：学习子图级解释（哪些连通区域关键）
    └─ 细粒度：学习边级解释（区域内哪些边更关键）

微调阶段（类感知正则化）：
    解释器输出 → 分类器
    损失 = 解释一致性 + 类间区分度正则
    使解释不仅能"解释预测"，还能"区分不同类"
```

#### 与本项目的对比分析

##### 相似之处

| 维度 | ReFine | 本项目 |
|------|--------|--------|
| **多粒度** | 粗粒度（子图）+ 细粒度（边） | 多粒度动作（节点/边/邻域/游走） |
| **类别区分** | 类感知微调使解释有区分性 | 揭示策略需要为不同类别找到不同证据 |

##### 关键差异

| 维度 | ReFine | 本项目 |
|------|--------|--------|
| **时序** | 事后——全图已知时做多粒度解释 | 事前——逐步揭示构建多粒度观测——根本差异 |
| **粒度来源** | 预训练+微调两阶段 | 原子动作→复合动作（成本组合） |
| **图可见性** | 完整图可见 | 逐步揭示 |
| **多粒度目的** | 提升人类可理解性 | 平衡揭示成本与信息量 |

> **启示**：ReFine 的多粒度思想验证了本项目的**动作粒度分层设计**——粗粒度的邻域揭示（H）+ 细粒度的节点/边揭示（N/E）——是从人类认知到机器决策的自然映射。

### 论文 5：RC-Explainer（模式分析与机器智能汇刊 2023, CCF-A 期刊）

| 维度 | 内容 |
|------|------|
| **论文名称** | Reinforced Causal Explainer for Graph Neural Networks |
| **作者** | Xiang Wang, Yingxin Wu, An Zhang, Fuli Feng, Xiangnan He, Tat-Seng Chua |
| **发表** | **IEEE TPAMI 2023**（IEEE Transactions on Pattern Analysis and Machine Intelligence） |
| **期刊等级** | **CCF-A 期刊**（人工智能/模式识别顶级期刊） |
| **arXiv** | [2204.11028](https://arxiv.org/abs/2204.11028) |

#### 摘要

可解释性对于探索 GNN 至关重要。特征归因是突出输入图中解释子图的流行技术。然而，大多数方法做了一个站不住脚的假设——所选边是线性独立的——从而很大程度上忽略边之间的依赖关系，特别是它们的联合效应。本文展示了该假设的明确缺陷——使解释子图不忠实且冗长。为此，我们提出强化因果解释器（RC-Explainer）——将解释任务框架化为顺序决策过程：通过依次添加显著边来构建解释子图。策略网络预测边添加动作并获得量化该动作对预测的因果效应的奖励。该奖励考虑了新添加边与先前添加边的依赖关系。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 边级独立假设忽视边的联合/组合效应 → 解释不忠实且冗余 |
| **核心贡献** | 将 GNN 解释建模为**顺序决策过程**（MDP）——策略网络逐边构建解释，奖励考虑边间因果依赖 |

#### 核心思路

```
解释=MDP（顺序边选择）：
    状态 s_t：当前已选边构成的子图
    动作 a_t：选择下一条要添加的边
    奖励 r_t：添加该边对预测的因果效应（ITECausal Effect）
    
    策略网络 π(a|s)：给定当前子图，输出每条候选边被选概率
    训练：REINFORCE 最大化累积因果效应奖励

因果效应度量：
    ITE(e | S_existing) = f(S_existing ∪ {e}) - f(S_existing)
    衡量在当前已选边集合基础上，新增边 e 的净因果贡献
```

#### 与本项目的对比分析

##### 相似之处

| 维度 | RC-Explainer | 本项目 |
|------|-------------|--------|
| **顺序决策** | 逐边选择构建解释子图（MDP） | 逐动作揭示构建观测图（MDP）——高度一致 |
| **依赖建模** | 边选择的因果效应考虑前后依赖 | 揭示动作的价值依赖前步观测 |
| **策略学习** | RL 训练策略网络（REINFORCE） | 启发式 → 模仿学习 → RL 策略 |
| **子图构建** | 从空子图出发逐步添加边 | 从空图 G₀ 出发逐步揭示 |

##### 关键差异

| 维度 | RC-Explainer | 本项目 |
|------|-------------|--------|
| **时序** | 事后——完整图已知时做解释 | 事前——逐步揭示后做预测——根本差异 |
| **图可见性** | 完整图已知（候选边池已知） | G₀ 渐进揭示（候选边动态出现） |
| **目标** | 解释已有预测（解释忠实度） | 做出正确预测（分类精度） |
| **奖励定义** | 因果效应（对预测的边际影响） | 信息增益 or 最终分类精度 |
| **动作空间** | 仅边添加（单一动作类型） | 节点/边/邻域/游走（多类型复合动作） |

> **启示**：RC-Explainer 是本项目中与 M4/M5 策略学习**方法论最接近**的论文。其 MDP 建模、REINFORCE 训练、因果奖励设计可以直接转化为揭示策略的训练框架——只需将"因果效应奖励"替换为"信息增益奖励"，将"边添加"扩展到多类型揭示动作。

### 论文 6：CF-GNNExplainer（人工智能与统计会议 2022, CCF-B）

| 维度 | 内容 |
|------|------|
| **论文名称** | CF-GNNExplainer: Counterfactual Explanations for Graph Neural Networks |
| **作者** | Ana Lucic, Maartje ter Hoeve, Gabriele Tolomei, Maarten de Rijke, Fabrizio Silvestri |
| **发表** | **AISTATS 2022**（International Conference on Artificial Intelligence and Statistics） |
| **期刊等级** | **CCF-B**（人工智能与统计重要会议） |

#### 摘要

鉴于 GNN 在实际应用中前景日益增长，已开发多种解释其预测的方法。现有方法主要生成与特定预测特别相关的子图（"为什么是这个预测？"）。然而，这些方法不一定会回答**反事实问题**——"需要改变什么才能使预测不同？"。本文提出 CF-GNNExplainer——首个生成 GNN 反事实解释的方法，定义为对输入图的最小扰动（边的删除），使得模型做出不同的预测。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 标准解释回答"为什么是 A"，不回答"为什么不是 B"（反事实） |
| **核心贡献** | 首个 GNN 反事实解释方法——最小边删除集合使预测翻转 |

#### 核心思路

```
标准解释（事实）：
    "哪些边导致预测为正类？" → 关键子图 G_S

反事实解释：
    "删除哪些边会使预测变为负类？" → 最小边集合 E_CF
    
优化：
    min |E_CF|  s.t. f(G \ E_CF) ≠ y_original
    最小扰动使预测翻转
```

#### 与本项目的对比分析

##### 相似之处

| 维度 | CF-GNNExplainer | 本项目 |
|------|----------------|--------|
| **最小化原则** | 最小扰动使预测翻转 | 最少预算使分类正确 |
| **选择性** | 只选最关键的边 | 只揭示最关键的证据 |

##### 关键差异

| 维度 | CF-GNNExplainer | 本项目 |
|------|----------------|--------|
| **解释类型** | 反事实（"为什么不是"） | 事实（"证据是什么"）——根本差异 |
| **操作方向** | 删除（从全图中移除边） | 添加（向空图中揭示边） |
| **图可见性** | 完整图已知 | 逐步揭示 |
| **目标** | 使已有预测翻转 | 做出正确预测 |

> **启示**：CF-GNNExplainer 的反事实思想可用于项目的**策略评估**——一个好策略不仅要揭示"支持正确分类的证据"，还应避免揭示"可能导致错误分类的误导信息"。反事实分析可为 M4 阶段的轨迹评分提供额外维度。

### 论文 7：GNNInterpreter（国际表征学习大会 2023, CCF-A）

| 维度 | 内容 |
|------|------|
| **论文名称** | GNNInterpreter: A Probabilistic Generative Model-Level Explanation for Graph Neural Networks |
| **作者** | Xiaoqi Wang, Han-Wei Shen |
| **发表** | **ICLR 2023** |
| **期刊等级** | **CCF-A**（表征学习顶级会议） |

#### 摘要

现有 GNN 解释方法主要关注**实例级解释**——解释模型为何对单个输入做出特定预测。然而，实例级解释难以提供对模型整体决策逻辑的全局理解。本文提出 GNNInterpreter——一种模型无关的**模型级解释方法**。GNNInterpreter 学习一个概率生成模型来生成最有可能激活特定类别的最具代表性图模式。与仅解释单个预测不同，GNNInterpreter 提供对 GNN 模型全局决策行为的更全面理解。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 实例级解释无法提供对 GNN 全局决策逻辑的理解 |
| **核心贡献** | 首个基于**概率生成模型**的 GNN 模型级解释——生成最能激活某类别的代表性子图 |

#### 核心思路

```
模型级解释（Class-level）：
    目标：对每一类 y，生成一个图 G* 使：
    G* = argmax_G P(f(G) = y)
    
    即 G* 是最能激活该类别的"理想图"
    
方法：学习图生成器，优化：
    1. 类别激活度（生成图属于目标类的概率高）
    2. 真实性（生成图像真实图）
    3. 紧凑性（生成图小而精）
```

#### 与本项目的对比分析

##### 相似之处

| 维度 | GNNInterpreter | 本项目 |
|------|---------------|--------|
| **类级理解** | 为每一类生成代表性图模式 | 揭示策略需要为不同类学习不同的"阅读偏好" |
| **紧凑性** | 追求小而精的代表图 | 预算约束天然限制大小 |

##### 关键差异

| 维度 | GNNInterpreter | 本项目 |
|------|---------------|--------|
| **解释粒度** | 模型级（全局决策逻辑） | 实例级（单图决策过程）——根本差异 |
| **输出** | 新生成的代表图（合成） | 从原始图逐步揭示子图 |
| **图可见性** | 不需要特定输入图 | 以特定输入图为目标 |
| **用途** | 审计/理解模型 | 实现模型预测 |

> **启示**：GNNInterpreter 的类级代表图可以转化为项目的**类级阅读偏好**——对某一类样本，最优揭示策略应该偏向某种拓扑结构（如分子图中某个官能团区域）。这为 M4/M5 的策略预训练提供了先验知识。

### 论文 8：XGNN（知识发现与数据挖掘会议 2020, CCF-A）

| 维度 | 内容 |
|------|------|
| **论文名称** | XGNN: Towards Model-Level Explanations of Graph Neural Networks |
| **作者** | Hao Yuan, Jiliang Tang, Xia Hu, Shuiwang Ji |
| **发表** | **KDD 2020** |
| **期刊等级** | **CCF-A**（数据挖掘顶级会议） |
| **arXiv** | [2006.02587](https://arxiv.org/abs/2006.02587) |

#### 摘要

GNN 通过聚合和组合邻居信息来学习节点特征，在许多图任务上取得了可喜的性能。然而，GNN 大多被视为黑箱，缺乏人类可理解的解释。本文提出 XGNN——首个 GNN 模型级解释方法。不同于解释单个实例，模型级解释旨在提供对 GNN 高层决策行为的全局洞察。XGNN 通过强化学习训练图生成器，生成最能最大化特定类别预测的图模式，为每个类别提供直观的代表性示例。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | GNN 被视为黑箱，缺乏模型级（而非实例级）解释 |
| **核心贡献** | 首个 GNN 模型级解释方法——RL 训练图生成器生成最优类别模式 |

#### 核心思路

```
XGNN 图生成（RL）：
    状态：当前部分生成的图
    动作：添加一个节点/边
    奖励：目标类别的预测概率
    
    策略：训练图生成器使生成图最大化目标类预测
    
输出：每个类别的代表图 → 直观展示"模型认为什么是A类"
```

#### 与本项目的对比分析

##### 相似之处

| 维度 | XGNN | 本项目 |
|------|------|--------|
| **RL 框架** | RL 训练图生成器（顺序添加节点/边） | RL/模仿学习训练揭示策略（顺序选择动作） |
| **动作空间** | 添加节点/边（与揭示动作类型类似） | 揭示节点/边/邻域/游走 |

##### 关键差异

| 维度 | XGNN | 本项目 |
|------|------|--------|
| **解释粒度** | 模型级——生成"理想样本"代表一个类 | 实例级——在具体图上做揭示决策——根本差异 |
| **图来源** | 从头生成新图（无中生有） | 从给定的真实图中逐步揭示 |
| **目标** | 解释模型全局行为 | 实现模型预测 |
| **预算** | 无硬约束（图大小由生成器控制） | 显式预算 B |

> **启示**：XGNN 的 RL 图生成框架在方法论上与项目的揭示策略极其相似——都是顺序添加动作。其动作空间设计（添加节点→添加边）可参考用于项目的揭示动作序列设计。

### 论文 9：GraphLIME（知识与数据工程汇刊 2022, CCF-A 期刊）

| 维度 | 内容 |
|------|------|
| **论文名称** | GraphLIME: Local Interpretable Model Explanations for Graph Neural Networks |
| **作者** | Qiang Huang, Makoto Yamada, Yuan Tian, Dinesh Singh, Yi Chang |
| **发表** | **IEEE TKDE 2022**（IEEE Transactions on Knowledge and Data Engineering） |
| **期刊等级** | **CCF-A 期刊**（数据库/数据挖掘顶级期刊） |

#### 摘要

GNN 在多个领域取得了显著成功，但它们是黑箱模型，缺乏可解释性。本文提出 GraphLIME——一种使用**希尔伯特-施密特独立准则（HSIC）Lasso**的图局部可解释模型解释方法，HSIC Lasso 是一种非线性特征选择方法。GraphLIME 是一个通用的 GNN 模型解释框架，通过训练局部可解释模型来逼近目标 GNN 在局部邻域的预测行为。其 N-跳采样策略和 HSIC Lasso 特征选择使解释既忠实于模型又简洁。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 缺乏基于非线性特征选择的忠实、简洁的 GNN 局部解释方法 |
| **核心贡献** | 将 LIME 框架扩展到图——用 HSIC Lasso（非线性独立性检验）替代线性 Lasso 选择关键节点特征 |

#### 核心思路

```
LIME 思想扩展到图：
    对目标节点 v 的 GNN 预测 f(v)：
    
    1. N-跳采样：采样 v 的邻域节点 → 局部数据集
    2. HSIC Lasso：在局部数据上选择最相关的特征子集
        HSIC 度量特征与预测的非线性依赖
    3. 局部解释模型：用选出的特征训练简单模型 → 解释
    
与标准 LIME 的区别：
    标准 LIME：线性模型 + Lasso → 仅捕获线性关系
    GraphLIME：HSIC Lasso → 捕获非线性特征依赖
```

#### 与本项目的对比分析

##### 相似之处

| 维度 | GraphLIME | 本项目 |
|------|-----------|--------|
| **局部视角** | 聚焦目标节点的局部邻域 | 聚焦已揭示的局部观测子图 |
| **特征选择** | HSIC Lasso 选择关键特征 | 揭示动作选择关键信息 |
| **N-跳采样** | 对邻域做 N-跳采样 | 邻域揭示（H-动作）做 K-跳揭示 |

##### 关键差异

| 维度 | GraphLIME | 本项目 |
|------|-----------|--------|
| **时序** | 事后——已有 GNN 预测后做解释 | 事前——逐步揭示后做预测——根本差异 |
| **特征选择粒度** | 选择"哪个特征维度重要" | 选择"哪个节点/边需要揭示" |
| **图可见性** | 完整图已知 | 逐步揭示 |
| **可解释模型** | 在局部训练简单模型（如线性）来解释 GNN | 分类器 φ 自身就是可解释的（揭示路径 = 解释） |

> **启示**：GraphLIME 的 N-跳邻域采样策略直接验证了我们邻域揭示（H-动作）的合理性——对目标节点，揭示其 k-跳邻域是获取局部信息的高效方式。HSIC Lasso 可用作揭示后"哪些已揭示特征最关键"的评估。

### 论文 10：RG-Explainer（神经信息处理系统进展 2021, CCF-A）

| 维度 | 内容 |
|------|------|
| **论文名称** | Reinforcement Learning Enhanced Explainer for Graph Neural Networks |
| **作者** | Caihua Shan, Yifei Shen, Yao Zhang, Xiang Li, Dongsheng Li |
| **发表** | **NeurIPS 2021** |
| **期刊等级** | **CCF-A**（人工智能顶级会议） |

#### 摘要

GNN 因其卓越性能而受到广泛关注，但其黑箱性质阻碍了在关键场景中的应用。尽管提出了几种事后解释方法，但仍存在挑战：(1) 解释子图的连通性未明确建模；(2) 难以确定解释子图的大小；(3) 在固定目标下难以评估质量。本文提出 RG-Explainer——包含三个主要组件的 RL 增强 GNN 解释器：**起点选择**、**迭代图生成**和**停止条件**。通过 RL 代理学习最优解释生成策略。在合成和真实数据集上的实验表明 RG-Explainer 能生成更连贯、更紧凑的解释。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 现有方法未建模子图连通性 + 大小难控制 + 缺乏统一评估 |
| **核心贡献** | 三组件 RL 框架——起点选择 + 迭代扩展 + 自停止——生成连通、紧凑的解释子图 |

#### 核心思路

```
三阶段 RL 解释生成：
    ┌─ 起点选择 ──────────────────┐
    │ RL agent 选择最有希望的起始节点  │
    └──────────────────────────────┘
                │
    ┌─ 迭代图生成 ─────────────────┐
    │ 从起点出发，RL 逐步添加邻居节点/边  │
    │ 奖励 = 当前子图的预测一致性      │
    └──────────────────────────────┘
                │
    ┌─ 停止条件 ───────────────────┐
    │ RL agent 学习何时停止扩展      │
    │ 奖励考虑紧凑性 + 忠实性        │
    └──────────────────────────────┘
```

#### 与本项目的对比分析

##### 相似之处

| 维度 | RG-Explainer | 本项目 |
|------|-------------|--------|
| **三阶段** | 起点→扩展→停止 | 初始揭示→迭代揭示→预算耗尽停止——高度一致 |
| **顺序性** | RL 代理逐步扩展子图 | 策略逐步揭示证据 |
| **连通性** | 显式建模子图连通性 | BFS/邻域揭示天然保证连通 |
| **自停止** | RL 学习何时停止 | 预算耗尽自动停止 or 策略输出 ∅ |

##### 关键差异

| 维度 | RG-Explainer | 本项目 |
|------|-------------|--------|
| **时序** | 事后——完整图已知时做解释 | 事前——逐步揭示后做预测——根本差异 |
| **停止方式** | 学习型（RL 决定何时停止） | 硬约束型（预算耗尽 or 策略主动终止） |
| **图可见性** | 完整图已知（候选邻居预知） | G₀ 渐进揭示（邻居动态出现） |
| **奖励定义** | 子图预测一致性（忠实度） | 信息增益 or 最终分类精度 |

> **启示**：RG-Explainer 的**三阶段 RL 框架**与我们的"初始揭示→迭代→停止"流程完全一致，是 M4/M5 策略学习的直接架构模板。其"学习何时停止"的能力在本项目中可以通过"策略输出 ∅"动作实现——当继续揭示的预期收益低于成本时自主停止。

### 关键差异标注

| 本项目的独特性 | 现有可解释性论文的共同局限 |
|---------------|--------------------------|
| **事前（pre-hoc）**——揭示在前，预测在后 | 全部是**事后（post-hoc）**——先有预测，后找解释 |
| **图不可见**——G₀ = (V, ∅, ∅)，逐步揭示 | 全部假设**完整图可见**（即使解释时只关注局部） |
| **显式预算**——B 单位原子成本 | 稀疏正则（软约束）或无约束 |
| **多动作类型**——节点/边/邻域/游走 | 边选择 or 子图选择（单一类型） |
| **面向预测**——揭示为了做预测 | **面向解释**——解释已有预测 |

> 基于 2026-5-17 方案，根据 2026-05-18 反馈修订：选定方案 D 的 G_0，冻结单一揭示动作 + 单位成本。

## 一、问题定义

### 1.1 自然语言描述

我们有一个图 G 和一个标签 y。开始时只能看到一个随机选取的种子节点及其关联边列表（邻居 ID），如同从一本合上的书中随机翻开一页——只看到该页的标题和它引用的其他页码编号，但不知道被引用页的内容，也不知道页面之间关系的性质。

我们有预算 B（允许揭示的节点数），可以执行一系列"揭示动作"——翻开一个新节点 v：看清 v 与已翻开节点之间所有边的特征，获取 v 的关联边列表（邻居 ID）作为下一步探索的线索。v 的邻居节点虽然 ID 已知，但其特征保持隐藏直到被独立揭示。

预算耗尽后，基于看到的部分信息做分类判断。目标是：同样预算下，比随机翻看得更准。

### 1.2 数学定义

给定图 $G = (V, E, X_E)$，$|V| = n$，标签 $y \in \{0, 1, \ldots, C-1\}$。初始观测 $G_0$（见第 2 节），预算 $B \in \mathbb{N}^+$，剩余预算 $B_{\text{current}} \in \mathbb{N}^+$。

**揭示动作**：$\mathcal{A} = \{\text{reveal\_node}(v) \mid v \in \text{frontier}(G_t)\}$

单位成本：$C(a) = 1, \quad \forall a \in \mathcal{A}$

**决策函数**：$\pi: (G_t, B_{\text{current}}) \to \mathcal{A} \cup \{\varnothing\}$

**更新函数**：$\psi: (G_t, a) \to G_{t+1}$

**分类器**：$\phi: G_{\text{final}} \to \hat{y}$

**决策过程**（$t = 1, 2, 3, \ldots$）：

$$
\begin{aligned}
B_{\text{current}}&\leftarrow\ B \\
\text{while } B_{\text{current}} > 0: & \\
&\quad a_t = \pi(G_{t-1}, B_{\text{current}}) \\
&\quad \text{if } a_t = \varnothing: \text{break} \\
&\quad B_{\text{current}} \leftarrow B_{\text{current}} - C(a_t) \\
&\quad G_t = \psi(G_{t-1}, a_t)
\end{aligned}
$$

**最终预测**：$\hat{y} = \phi(G_{\text{final}})$

**优化目标**：

$$
\max_{\pi, \phi} \; \mathbb{E}_{(G,y) \sim \mathcal{D}}\Big[\mathbb{1}(\hat{y} = y)\Big] \quad \text{s.t.} \quad \sum_{t} C(a_t) \leq B
$$

**最大化期望准确率**：在数据分布 $\mathcal{D}$ 上，随机抽取一个图 $G$ 及其真实标签 $y$，策略 $\pi$ 和分类器 $\phi$ 依次执行动作、更新观测，最终预测 $\hat{y}$。目标是最优化预测正确的概率。

## 二、G_0 初始观测（方案 D：k-Seed）

### 2.1 G_0 定义

```
G_0: 随机选取 k 个种子节点（v0 中 k = 1），对每个种子节点：
     ✓ 节点 ID 已知
     ✓ 关联边列表 / 邻居 ID 已知（边存在性）
     ✓ 边特征：仅当边的两个端点都已揭示时才可见
     ✗ 种子节点特征隐藏（OGBG-PPA 无节点特征）
     ✗ 非邻居节点 ID 未知
     ✗ 全局图规模（|V|）未知
```

### 2.2 形式化

令 $S = \{s_1, \ldots, s_k\} \subset V$ 为随机选取的种子节点集，$k \ll n$（v0 中 $k = 1$）。

初始状态 $G_0$ 揭示的信息：


| 揭示内容               | 符号                                                            | 说明                                       |
| ---------------------- | --------------------------------------------------------------- | ------------------------------------------ |
| 种子节点 ID            | $V_{\text{revealed}}^{(0)} = S$                                 | k 个已知节点                               |
| 关联边列表             | $E_{\text{known}}^{(0)} = \{(u, w) \mid u \in S, (u,w) \in E\}$ | 种子节点的所有邻居 ID 已知，边存在性已知   |
| 边特征（已揭示节点间） | $X_E^{(0)} = \varnothing$                                       | $k=1$ 时无双端点均已揭示的边，无边特征可见 |
| 节点特征               | $X_V^{(0)} = \varnothing$                                       | OGBG-PPA 无节点特征                        |

### 2.3 设计理由


| 对比维度       | 方案 A（原版）     | 方案 D（v0 采用）      |
| -------------- | ------------------ | ---------------------- |
| G_0 可见内容   | 所有节点 ID        | k 个种子节点 + 邻居 ID |
| 图规模         | 已知               | V                      |
| "免费信息"量   | 全部节点索引       | 仅种子局部邻域         |
| 现实对应       | "知道整本书的目录" | "从书中随机翻开一页"   |
| 适合数据集规模 | 小图（~10 节点）   | 大图（~100-10k 节点）  |

方案 A 在 PPA 级规模（单图数百节点）下，"所有节点 ID 可见"本身就是不切实际的免费读取。方案 D 的 k-seed 设定匹配"从单一入口点开始探索"的真实场景。

### 2.4 初始状态示意

```
              (邻居2 ID=5)          (邻居3 ID=7)
                   |                    |
              [边存在]              [边存在]
                   |                    |
            ┌──────┴──────┬─────────────┴────┐
            |                              |
         种子节点 s                    (邻居1 ID=3)
       (ID=0, 已揭示)                      |
            |                          [边存在]
            └──────────────────────────────┘
    
  G_0：种子节点 s + 其 3 个邻居的 ID = {3, 5, 7} + 边存在性
  边特征：无（无双端点揭示）
  邻居特征：隐藏
  图总节点数：未知（实际可能远大于 4）
```

## 三、核心揭示动作

### 3.1 动作定义

**唯一动作类型**：`reveal_node(v)`

**前置条件**：$v \in \text{frontier}(G_t)$，即 v 必须是某个已揭示节点的邻居（ID 已知但尚未揭示）。

**揭示内容**：


| #  | 揭示项                     | 说明                                                                                        |
| -- | -------------------------- | ------------------------------------------------------------------------------------------- |
| ① | v 成为已揭示节点           | $V_{\text{revealed}}^{(t+1)} = V_{\text{revealed}}^{(t)} \cup \{v\}$                        |
| ② | v 与已揭示节点之间的边特征 | $X_E^{(t+1)} = X_E^{(t)} \cup \{x_{vu} \mid u \in V_{\text{revealed}}^{(t)}, (v,u) \in E\}$ |
| ③ | v 的关联边列表 / 邻居 ID   | 新邻居 ID 加入 frontier（边存在性已知，但邻居特征隐藏）                                     |

**不揭示的内容**：

- ✗ 新发现邻居的节点特征（保持隐藏，直到被独立 `reveal_node`）
- ✗ v 与尚未揭示节点之间的边特征（双方均揭示后才可见）
- ✗ 图的其他部分（未被 frontier 覆盖的区域仍不可达）

### 3.2 形式化状态转移

$$
\begin{aligned}
G_t &= (V_{\text{revealed}}^{(t)},\; E_{\text{known}}^{(t)},\; X_E^{(t)},\; X_V^{(t)}) \\[6pt]
G_{t+1} &= \psi(G_t, \text{reveal\_node}(v)) \quad \text{其中：} \\[4pt]
V_{\text{revealed}}^{(t+1)} &= V_{\text{revealed}}^{(t)} \cup \{v\} \\[4pt]
E_{\text{known}}^{(t+1)} &= E_{\text{known}}^{(t)} \cup \{(v, w) \mid (v,w) \in E\} \\[4pt]
X_E^{(t+1)} &= X_E^{(t)} \cup \{x_{vu} \mid u \in V_{\text{revealed}}^{(t)}, (v,u) \in E\} \\[4pt]
X_V^{(t+1)} &= X_V^{(t)} \quad (\text{OGBG-PPA 无节点特征})
\end{aligned}
$$

**frontier 更新**：

$$
\text{frontier}(G_{t+1}) = \left(\text{frontier}(G_t) \setminus \{v\}\right) \cup \{w \mid (v,w) \in E,\; w \notin V_{\text{revealed}}^{(t+1)}\}
$$

### 3.3 成本

**单位成本**：$C(\text{reveal\_node}(v)) = 1$

**累计成本**：$\sum_t C(a_t) = \text{已揭示节点数} \leq B$

预算 $B$ 的含义：**允许揭示的最大节点数**（不含种子节点）。

### 3.4 揭示过程示意（t=0 → t=1）

```
t=0（G_0）:                              t=1（reveal_node(v=3)）:
  
  种子 s (ID=0) ✓已揭示                   种子 s (ID=0) ✓已揭示
  ├─[边]→ 邻居 3 (ID=3) ← frontier        ├─[边=特征值0.7]→ 邻居 3 ✓已揭示
  ├─[边]→ 邻居 5 (ID=5) ← frontier        ├─[边]→ 邻居 5 (ID=5) ← frontier  
  └─[边]→ 邻居 7 (ID=7) ← frontier        ├─[边]→ 邻居 7 (ID=7) ← frontier
                                           │
                                           └─ 节点 3 的邻居：
                                                ├─[边]→ 邻居 9 (ID=9) ← 新frontier
                                                └─[边]→ 邻居 0 (ID=0,既s) (已揭示，边特征已知)

  B_current = B - 1                       前沿扩展：frontier = {5, 7, 9}
```

## 四、基准策略

v0 阶段对比以下三种策略，均从前沿（frontier）中选择下一个揭示节点：

### 4.1 策略清单


| 编号 | 策略名称                      | 选择规则                                 | 说明                            |
| ---- | ----------------------------- | ---------------------------------------- | ------------------------------- |
| P1   | **Uniform Random**            | $v \sim \text{Uniform}(\text{frontier})$ | 前沿中均匀随机选择，无信息基准  |
| P2   | **BFS Order**                 | 按发现顺序（FIFO 队列）                  | 从种子开始逐层扩张              |
| P3   | **Max Known-Frontier Degree** | $v = \arg\max_{u \in \text{frontier}}$   | $N(u) \cap V_{\text{revealed}}$ |

**重要说明**：

- P3 中的"度" = 前沿节点与已揭示节点集之间的边数（**已知图的局部度**），而非真实图度（隐藏信息）。该指标衡量节点与当前已观测子图的连接强度。
- 三种策略均从前沿中选择，不可选择不在前沿中的节点（因为其 ID 未知）。

### 4.2 种子平均

由于 $k=1$ 随机种子对早期性能影响可能较大，每种策略在每张图上对多个随机种子取平均后报告。

### 4.3 全图上界

训练一个标准 GIN 或 GCN 分类器在全图（全部节点/边/特征可见）上的准确率，作为所有预算-性能曲线的上界参照。这是最重要的基准数字。

## 五、预算与评价指标

### 5.1 预算设置


| 表示方式        | 说明                   |
| --------------- | ---------------------- |
| 绝对计数$B$     | 揭示节点数（不含种子） |
| 相对比例$B / n$ | 揭示比例，跨图可比     |

推荐预算序列：$B / n \in \{1\%, 2\%, 5\%, 10\%, 20\%, 50\%\}$（向上取整至整数节点数），同时报告 $n$ 的分布。

### 5.2 核心指标

1. **预算-准确率曲线**：$B / n$ vs. 分类准确率，每种策略一条曲线
2. **全图上界**：全图 GIN/GCN 准确率（虚线标注）
3. **曲线下面积（AUC-B）**：预算-准确率曲线的积分，单数值汇总策略表现
4. **BFS-to-upper ratio**：BFS 在低揭示比例（<10%）下达到全图准确率的百分比——若 >90%，数据集对本问题太简单（触发淘汰标准）

### 5.3 淘汰标准（Kill Criterion）

若 BFS-from-seed 在小揭示比例（<10% 节点）下已达到全图准确率的 ~90%，则该数据集对本问题过易——揭示策略的选择不再重要。此时应切换到更困难的数据集或更困难的 $G_0$，再投入 M4/M5 阶段。

## 六、数据集：OGBG-PPA

### 6.1 选择理由

- MUTAG（~18 原子/图）仅作为玩具示例，不构成 M3 基准
- OGBG-PPA 单图规模（数百节点、数千边）使"读取全图不免费"的假设成立
- 图分类任务，与项目目标一致

## 一、方案 A：纯图阅读（Pure Graph Reading）—— M3 默认

### 1.1 G_0 初始观测

```
G_0 = (V, ∅, ∅)
```


| 可见                      | 不可见        |
| ------------------------- | ------------- |
| 节点索引 {0, 1, ..., n-1} | 节点特征 X    |
| 图规模                    | V             |
| —                        | 节点标签/类型 |
| —                        | 全局图属性    |

最纯粹的问题设定——"一本合上的书，只有目录（章节编号），但不知道每章讲什么、章节之间如何关联"。

### 1.2 核心动作

每步选择一个节点 ID，揭示该节点的全部特征向量 + 该节点与所有其他节点之间的边。对未揭示的邻居仅暴露其节点 ID（不含特征），作为"下一步可以去哪里"的线索。

### 1.3 成本模型

见章节二。因 G_0 无任何信息，模型无法预判哪个节点"更贵"——统一成本是"无知先验"。

### 1.4 数学定义

**自然语言**：

我们有一个图 G 和一个标签 y。开始时只能看到节点编号——G_0 = (V, ∅, ∅)，像一本合上的书的目录。我们有预算 B，可以执行一系列"揭示动作"——翻开某一页看内容（节点揭示）、查看两页之间是否有引用（边揭示）、一次性翻开一个章节看清所有关联页（邻域揭示）、或沿线索链追踪下去（随机游走揭示）。每次动作消耗的预算取决于动作类型和图的局部结构。预算耗尽后，基于看到的部分信息做分类判断。目标是：同样预算下，比随机翻看得更准。

**数学符号**：

给定图 $G = (V, E, X)$，$|V| = n$，标签 $y \in \{0, 1, \ldots, C-1\}$。初始观测 $G_0 = (V, \varnothing, \varnothing)$，预算 $B $,剩余预算$B_{current}\in \mathbb{N}^+$。

**原子动作** $\mathcal{A}_{\text{atom}} = \{\text{reveal\_node}, \text{reveal\_edge}, \text{reveal\_node\_f}, \text{reveal\_edge\_f}\}$

原子成本函数 $c: \mathcal{A}_{\text{atom}} \to \mathbb{R}^+$：

**复合动作** $\mathcal{A} = \{N, N^+, N^-, E, E_f, H, H^-, W, W^+, H_k, U_1, U_2, \ldots\}$详见成本模型

每个 $a \in \mathcal{A}$ 分解为原子动作的多重集 $a = \{\text{atom}_1, \ldots, \text{atom}_m\}$，成本可加：$C(a) = \sum_{i=1}^{m} c(\text{atom}_i)$

$决策函数：\pi：(G,B_{current}) \rightarrow\ \mathcal{A} \\  \\更新函数：\psi：（G，a）\rightarrow\ G'\\  \\分类器\phi: G_{\text{final}}\rightarrow\ \hat{y}$

**决策过程**（$t = 1, 2, 3, \ldots$）：

$B_{current}=B\\while(B_{current}):\{\\ a_t = \pi(G_{t-1},B_{current})\\if(a_t== \varnothing)break;\\ B_{curent}  \leftarrow B_{curent} - C(a_t),\\G_t = \psi(G_{t-1}, a_t)\\\}$

**最终预测**：$\hat{y} = \phi(G_{\text{final}})$

**优化目标**：$\max_{\pi, \phi} \; \mathbb{E}_{(G,y) \sim \mathcal{D}}\Big[\mathbb{1}(\hat{y} = y)\Big] \quad \text{s.t.} \quad \sum_{t} C(a_t) \leq B$

**最大化期望准确率**：在数据分布$\mathcal{D}$上，随机抽取一个图 G及其真实标签 y，策略 π 和分类器 ϕ 依次执行动作、更新观测，最终预测 。目标是最优化预测正确的概率。

### 1.5 方案优点

1. **最纯粹的问题设定**：没有任何先验泄露，策略从零建立对图的理解
2. **基准设计最简单**：统一成本 + 单一动作类型，超参数最少（仅 B）
3. **策略差异最大化**：好策略和坏策略差距最大——随机揭示 vs. BFS/度中心性
4. **可扩展性强**：方案 A 是所有其他方案的"基类"
5. **与现有 GNN 基准兼容**：只需添加"隐藏层"，不需要修改数据格式

### 1.6 方案缺陷

1. **初始选择完全盲目**：第一步必然等价于随机选择（B 很小时高方差）
2. **不贴合真实应用**：实际中几乎没有"只知道节点数量"的场景
3. **图的"规模效应"未体现**：n=100 和 n=10000 的图在 G_0 中完全相同
4. **"关联边"的半透明语义模糊**：未揭示邻居仅显示 ID，引入信息不对称中间态

## 二、统一成本模型：四个原子动作

### 2.1 设计动机

方案 A 中所有动作统一成本 = 1，简单但不真实。方案 B/C/D 各有不同的成本模型（度数加权、层级成本、特征维度加权）。四个方案需要一个**统一的底层成本模型**——所有复合揭示动作的成本由四个原子动作的线性组合计算。不同方案的区别仅在于 G_0 中已"免费"获得了哪些原子信息。

### 2.2 四个原子动作


| 编号 | 原子动作             | 揭示内容                       | 符号 | 默认值 |
| ---- | -------------------- | ------------------------------ | ---- | ------ |
| (0)  | `reveal_node(v)`     | 揭示节点 v 的存在性（ID）      | c_n  | **1**  |
| (1)  | `reveal_edge(u,v)`   | 揭示边 (u,v) 的存在性          | c_e  | **1**  |
| (2)  | `reveal_node_f(v)`   | 揭示节点 v 的存在性 + 全部特征 | c_nf | **2**  |
| (3)  | `reveal_edge_f(u,v)` | 揭示边 (u,v) 的存在性 + 边特征 | c_ef | **2**  |

**设计逻辑**：

- 基础单位 = 1，"存在性"是最小的信息量子
- "特征"在存在性基础上追加 1 单位：c_nf = c_n + 1 = 2, c_ef = c_e + 1 = 2
- 已揭示存在性再追加特征，增量 = c_nf − c_n = 1

**参数化形式**（消融实验用）：

```
c_n  = 1                       （节点存在性，基础单位）
c_e  = 1                       （边存在性）
c_nf = c_n + δ_node_feat       （δ_node_feat ≥ 0，默认 = 1）
c_ef = c_e + δ_edge_feat       （δ_edge_feat ≥ 0，默认 = 1）
```

### 2.3 成本组合规则

任何复合揭示动作的成本 = 其分解出的原子动作成本之和。

**示例**："揭示 v 的特征 + 邻居节点 ID（不含邻居特征），v 有 k 个邻居"

```
cost = reveal_node_f(v) + k × reveal_node(u)
     = c_nf + k × c_n = 2 + k
```

### 2.4 四大类揭示动作（按粒度分层）

```
粒度粗、信息量大  →  邻域揭示：默认获取所有节点特征 + 边特征
粒度中、信息量中  →  节点揭示：默认获取节点特征 + 边存在性（不含边特征）
                  →  随机游走：默认获取节点特征 + 边存在性（不含边特征）
粒度细、信息量小  →  边揭示：  存在性/特征分离，由调用者选择
```

#### 节点揭示（Node Reveal）—— 中等粒度


| 编号  | 动作                                | 揭示内容                          | 符号成本       | k=3   |
| ----- | ----------------------------------- | --------------------------------- | -------------- | ----- |
| **N** | `reveal_node(v)` **(默认)**         | v 的特征 + 所有关联边（存在性）   | c_nf + k·c_e  | **5** |
| N+    | `reveal_node_with_edge_features(v)` | v 的特征 + 所有关联边（含边特征） | c_nf + k·c_ef | 8     |
| N−   | `reveal_node_features_only(v)`      | 仅 v 的特征（不揭示边）           | c_nf           | 2     |

> N（默认）= 原方案 A 的核心动作。

#### 边揭示（Edge Reveal）—— 细粒度


| 编号   | 动作                 | 揭示内容                   | 符号成本 | 数值  |
| ------ | -------------------- | -------------------------- | -------- | ----- |
| **E**  | `reveal_edge(u,v)`   | 边 (u,v) 的存在性          | c_e      | **1** |
| **Ef** | `reveal_edge_f(u,v)` | 边 (u,v) 的存在性 + 边特征 | c_ef     | **2** |

> 粒度最细，存在性和特征分离，按需选择。

#### 邻域揭示（Neighborhood Reveal）—— 粗粒度


| 编号  | 动作                                | 揭示内容                                         | 符号成本                | k=3    |
| ----- | ----------------------------------- | ------------------------------------------------ | ----------------------- | ------ |
| **H** | `reveal_neighborhood(v)` **(默认)** | v + 1-hop 邻居（含特征）+ 所有关联边（含边特征） | c_nf + k·(c_nf + c_ef) | **14** |
| H−   | `reveal_neighborhood_edges_only(v)` | v + 1-hop 邻居（含特征）+ 所有关联边（仅存在性） | c_nf + k·(c_nf + c_e)  | 11     |
| Hk    | `reveal_khop(v, m)`                 | m-hop 自我网络（全含边特征）                     |                         | V_m    |

> H（默认）一次揭示完整 1-hop ego-net。粗粒度 → 全含边特征。

#### 随机游走揭示（Random Walk Reveal）—— 中等粒度


| 编号  | 动作                                     | 揭示内容                                       | 符号成本              | L=5    |
| ----- | ---------------------------------------- | ---------------------------------------------- | --------------------- | ------ |
| **W** | `reveal_walk(v_0, L)` **(默认)**         | L 步游走，L+1 节点（含特征）+ L 条边（存在性） | (L+1)·c_nf + L·c_e  | **17** |
| W+    | `reveal_walk_with_edge_features(v_0, L)` | 同上 + 边特征                                  | (L+1)·c_nf + L·c_ef | 22     |

> 随机游走与有偏游走成本相同——成本由步数决定，不由转移策略决定。统一记为 `reveal_walk`。

#### 证据单元揭示（Evidence Unit Reveal）—— M4/M5 阶段

证据单元是预定义的语义子结构（如分子图中的官能团 NO₂、COOH、苯环），一次揭示整个子结构。


| 编号 | 动作变体                        | 揭示内容                                                    | 符号成本                      |
| ---- | ------------------------------- | ----------------------------------------------------------- | ----------------------------- |
| U1   | `reveal_evidence_unit(e)`       | 揭示证据单元 e 的所有节点（含特征）+ 所有内部边（含边特征） | \|V_e\|·c_nf + \|E_e\|·c_ef |
| U2   | `reveal_evidence_unit_basic(e)` | 同上但边仅存在性                                            | \|V_e\|·c_nf + \|E_e\|·c_e  |

**本质**：证据单元揭示 = 对一个已知子图的"批量 ego-net 揭示"。成本无新原子动作，直接复用现有原子成本求和。其特殊性在于 **"选择"机制**（需要先验知识定义何为证据单元），而非成本结构。

### 2.6 组合/分解关系

```
N  = N− + k×E          （节点揭示 = 节点特征 + k 条边存在性）
H  = N− + k×N− + k×Ef  （邻域揭示 = 中心节点特征 + k 个邻居特征 + k 条边特征）
H− = N− + k×N− + k×E   （同上，边仅存在性）
W  = (L+1)×N− + L×E    （游走揭示 = L+1 个节点特征 + L 条边存在性）
W+ = (L+1)×N− + L×Ef   （同上，边含特征）
```

### 2.7 预算校准

原方案 A：B ∈ {1, 2, 3, 5, 10, 15}，统一成本 = 1。

Base 方案推荐 B ∈ {**2, 5, 8, 12, 20, 30**}：


| B  | 能做的事                                     |
| -- | -------------------------------------------- |
| 2  | 1×N− 或 2×E 或 1×Ef（最小有意义动作）    |
| 5  | 1×N（原方案 A 核心动作）                    |
| 12 | 1×H−（邻域降级版）或 2×N + 2×E（混合）   |
| 20 | 1×W（短游走）或 1×H + 1×N（邻域+节点）    |
| 30 | 1×H + 1×W（邻域+游走组合）或更复杂混合策略 |

### 2.8 跨方案扩展

原子成本模型与 G_0 无关，可直接复用：


| 方案 | G_0                 | 已"免费"的信息         | 成本影响                      |
| ---- | ------------------- | ---------------------- | ----------------------------- |
| A    | (V, ∅, ∅)         | 所有节点 ID            | 节点/边特征均需付费           |

不同方案的预算"购买力"不同——跨方案比较时需归一化。

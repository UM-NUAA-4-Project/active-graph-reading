# M4 Trajectory 轨迹数量与交叉熵联合分析报告

## 一、基础数据整理

### 生成方法

- **T1 (gradient)**：选梯度归因分数最高的 frontier node；生成轨迹
- **T2 (structural)**：选 degree/pagerank 最高的 frontier node；生成轨迹
- **T4 (hybrid)**：打分时使用 α·T1 + (1-α)·T2（α=0.30 / α=0.70）
- 每个 teacher 先全图打分，选出 top-k 最优点开始尝试（k=2）
- 数据来源于 4 种预算（0.05, 0.10, 0.15, 0.20），78200 图

## 二、优化策略

### 2.1 0.20 预算的边际贡献


| 指标           | 0.05   | 0.10    | 0.15   | 0.20     |
| -------------- | ------ | ------- | ------ | -------- |
| 总轨迹数       | 27,321 | 37,347  | 40,804 | 40,996   |
| 增量           | —     | +10,026 | +3,457 | **+192** |
| missing 类别数 | 13     | 5       | 4      | 3        |

0.15→0.20 仅新增 192 条轨迹（+0.5%），missing 类别仅从 4→3（class 13 重新出现，0.10可以检测到class 13），**0.20 未带来实质性突破**。

### 2.2 裁剪策略

- **主体**：仅使用 [0.05, 0.10, 0.15] 三个预算
- **例外**：总轨迹数 < 1000 的类别保留 0.20（共 22 类，这些类的 0.20 贡献了约 33% 的轨迹，不可忽略）
- **被裁类别**（总 ≥ 1000，丢弃 0.20）：1, 2, 3, 4, 6, 12, 17, 18, 21, 23, 24, 33, 36（共 13 类）

### 2.3 补充策略

裁剪后总数 < 200 的类别需额外生成轨迹（增加 teacher尝试次数k ）：0, 5, 10, 11, 13, 14, 16, 19, 20, 27, 28, 30, 32（共 13 类）

### 2.4 类内筛选

使用余弦相似度去重：`sim = |交集| / |v1|`，sim > 0.85 的轨迹只保留 CE 最低者。先按 CE 升序排列，贪心保留。

## 一、Base Reader 增强

### 1.1 架构回顾

Base Reader 管线如下：

```
GraphState → FrontierGraphBuilder → FrontierSubgraph
  → FrontierNodesEncoder (2-layer GINE, hidden=128)
    节点初始特征: type_embedding (revealed=0, frontier=1)
    边特征: 7-dim 原图边特征
  → frontier_embeds (N_f × 128)
  → 拼接 [frontier_embeds ‖ budget_ratio(1) ‖ struct_v(3)] = N_f × 132
  → ReaderMLP (132→128→128→1)
  → softmax → select node → reveal_node → 循环
```

经两次关键改动后收敛。

### 1.2 损失函数与奖励设计

**问题**：初始版本 loss 和 reward 导致平均 R < 0（不如随机），训练不稳定。

**修改**：


| 改动     | 内容                                                                                                       | 效果                                    |
| -------- | ---------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| 损失函数 | BC 每步 loss 按时序权重求和：`loss = Σ w_t · CE(π_t, a*_t)`，其中 `w_t = softmax(2t/B)`，后期步权重更大 | 提高后期决策质量                        |
| 奖励设计 | `R = tanh(1 - CE/ln(K))`，连续奖励 ∈ (-1, 1)，0 = 随机水平                                                | 解决 R < 0 问题，初始平均 R 提升到 0.3+ |

**RL 训练中的奖励**（`train_rl.py`）：

```
REINFORCE: -R · Σ w_t · log π_t(a_t) + β · CE(classifier_logits, y)
  w_t = softmax(2t/B)    逐步加权，跨 budget 一致
  R = tanh(1 - CE/ln(K))  连续 reward，K=37
```

### 1.3 特征添加

ReaderMLP 的输入从原始的 128 维（仅 frontier embedding）扩展到 132 维，新增两组特征：


| 特征           | 维度 | 含义                                   | 添加原因                                     |
| -------------- | ---- | -------------------------------------- | -------------------------------------------- |
| `budget_ratio` | 1    | 剩余预算比例`1 - t/B`                  | 提供时域信号，区分"探索期"和"利用期"         |
| `struct_v`     | 3    | 归一化度 + 归一化前沿度 + 局部聚类系数 | 提供局部拓扑信息，辅助区分质量相近的候选节点 |

**消融验证（Phase 2 初步结果）**：


| 配置                | 决策一致性(vs A0) | 含义                                             |
| ------------------- | ----------------- | ------------------------------------------------ |
| A1: 去 budget_ratio | 1.000             | 置零不影响决策（对训练好的 reader 信号已被内化） |
| A2: 去 struct_v     | 1.000             | 置零不影响决策                                   |
| A4: 去 edge_feat    | 0.013             | 边特征是 reader 决策的**核心依赖**               |

结论：`edge_feat >> budget_ratio > struct_v`。边特征（7 维原始图边特征）是 PPA 数据集上区分 frontier 节点的唯一有效信号通道，因为 PPA 无节点特征。budget_ratio 和 struct_v 在 BC 训练中已被编码器隐式吸收，推断时显式置零不影响已收敛 reader 的选择。

## 三、Phase 4：分类质量与信息积累分析

### 3.1 实验设置


| 参数              | 取值                                                                  |
| ----------------- | --------------------------------------------------------------------- |
| Reader checkpoint | `m5/base/rl/checkpoint_epoch7.pt`                                     |
| Classifier        | `m3/best_model_ft.pt`（冻结，val_acc=64.19%）                         |
| 数据集            | PPA val split，**均匀抽样 5000 张图**（每类 135-137 张，37 类全覆盖） |
| Budget            | 10%                                                                   |
| Seed              | best-seed（max-degree 节点）                                          |

### 3.2 整体表现


| 指标                          | 数值                 | 解读                                                                                 |
| ----------------------------- | -------------------- | ------------------------------------------------------------------------------------ |
| **最终分类准确率**            | **8.48%** (424/5000) | 仅约 3 倍于随机基线（2.70%），远低于 BC 时 Phase 1 全量评测的 12.49%（均匀抽样造成） |
| 平均翻转次数/图               | 2.92                 | reader 在探索过程中频繁改变分类判断                                                  |
| 翻向正确 vs 翻向错误          | 1,018 vs 13,557      | 93% 的翻转向错误方向                                                                 |
| 从未锁定（never locked）      | 4,576 张 (91.52%)    | 绝大多数图在预算耗尽时仍未稳定正确                                                   |
| 锁定点均值（确锁定的 424 张） | t*/B = 0.523         | 即使能锁定的图，也需要消耗过半预算                                                   |

### 3.3 信息积累曲线

**CE_t 曲线**：交叉熵从 t/B=0.05 时的 37.08 单调下降至 t/B=1.0 时的 31.36。这一绝对值极高——CE=3.61 对应随机猜测（概率 ≈ 1/37），CE=37 意味着 classifier 将正确类别的概率估为 exp(-37) ≈ 8.5×10^{-17}，即**几乎为零**。

**top1_prob_t 曲线**：classifier 的最大 softmax 概率从 0.825 上升至 0.885。**classifier 对子图的预测高度自信（82-89%），但自信在错误答案上**（准确率仅 8.48%）。这是子图分类器校准失效的典型表现——classifier 在全图上训练（val_acc=64.19%），但在仅揭示 10% 节点的稀疏子图上，其输出的 top-1 概率已不反映真实的分类正确率。

**R_t 曲线**：即时奖励从 -0.913 上升至 -0.801。始终为负（0 = 随机水平），说明每步子图分类质量始终低于随机猜测的交叉熵基线。

### 3.4 ΔCE_t 信息增益递减


| 阶段            | ΔCE_t 均值 | 占总量比 |
| --------------- | ----------- | -------- |
| Early（前 1/3） | 0.689       | 58.8%    |
| Mid（中 1/3）   | 0.282       | 24.1%    |
| Late（后 1/3）  | 0.194       | 17.1%    |

每步信息增益从早期到晚期下降 72%（0.689 → 0.194），呈现明显的**边际收益递减**模式。早期几步揭示的节点包含最多的判别信息，后期揭示的节点对 CE 降低的贡献逐渐衰减。

**启示**：这为 POMDP 的 Submit-Early 机制提供了实证支撑——若能在信息增益降至阈值（如 ΔCE_t < 0.2）时终止探索，可以在不显著损失分类质量的前提下节省预算。

### 3.5 Per-Class 分类质量

37 个类别的准确率分布呈现出极端的两极分化：


| 分类   | 阈值   | 类别数 | 占比  |
| ------ | ------ | ------ | ----- |
| 容易类 | ≥80%  | 0      | 0%    |
| 中等类 | 40-80% | 2      | 5.4%  |
| 困难类 | <40%   | 35     | 94.6% |

**表现最好的类**：


| 类 | 准确率 | 样本数 |
| -- | ------ | ------ |
| 6  | 57.0%  | 135    |
| 17 | 54.0%  | 137    |
| 23 | 27.4%  | 135    |

**准确率为 0 的类（12 个）**：0, 5, 10, 11, 13, 16, 19, 20, 25, 26, 27, 28, 30, 32, 35——这些类的子图在 10% budget 下完全无法被 classifier 正确识别。

仅有两个中等类（6 和 17）超过 50%，说明 reader 的策略对少数特定类有效，但对大多数类完全无效。

### 3.6 混淆矩阵分析

Top-10 误分类对揭示了一个关键模式：**大量不同类被错误地归类到少数几个"吸引子"类**：


| 排名 | True → Pred | 次数 | 解读                                      |
| ---- | ------------ | ---- | ----------------------------------------- |
| 1    | 31 → 6      | 106  | 类 6 是最大吸引子（同时也是最好分类的类） |
| 2    | 30 → 6      | 93   | 类 6 吸收了大量类 30 的样本               |
| 3    | 4 → 33      | 74   | 类 33 是次大吸引子                        |
| 4    | 9 → 6       | 73   | 类 6 继续吸收                             |
| 5    | 26 → 36     | 71   |                                           |
| 6    | 16 → 23     | 62   |                                           |
| 7    | 20 → 2      | 60   |                                           |
| 8    | 15 → 17     | 59   | 类 17 也吸收其他类                        |
| 9    | 25 → 36     | 57   |                                           |
| 10   | 13 → 2      | 57   |                                           |

类 6 和类 17 在 per-class 分析中表现最好（57% 和 54%），但混淆矩阵显示它们之所以"好"，是因为**classifier 倾向于将所有不确定的图都预测为这几个类**。这不是 strategy 选择好，而是 classifier 在稀疏子图上的**预测偏差**——当信息不足时，classifier 坍缩到少数几个"默认"输出类。

### 3.7 诊断结论

Phase 4 的结果揭示的不是 reader 策略问题，而是**base reader 架构层面的系统性缺陷**：

1. **采样与判断分离**（sampling-judgment decoupling）：reader 负责选节点（探索），但最终的分类由**冻结的** GraphClassifier 完成。这个 classifier 在全图上训练（64.19% val acc），从未见过稀疏子图（仅 10% 节点揭示）。当子图信息严重不足时，classifier 的输出呈现两个退化行为：(a) **过度自信**（top1_prob=0.85-0.89 但准确率=8.5%）；(b) **类别坍缩**（多数图被预测到少数几个"默认"类）。
2. **Reader 的信号瓶颈**：reader 试图优化 classifier 的 CE，但 classifier 本身在稀疏子图上校准失效——reader 再怎么优化探索策略，也无法弥补 classifier 在低信息输入下的系统性偏差。这解释了为什么 BC 训练集上子图分类正确率 0.65+，但 val 仅 8.48%——BC 训练的 teacher 动作选择基于训练集上的 classifier 反馈，但该反馈在 val 集上不泛化。
3. **信息增益的早熟衰退**：ΔCE_t 从 early 的 0.69 骤降到 late 的 0.19，说明前几步揭示的节点贡献了大部分信息。这既是好消息（不需要很多步就能获得主要信息），也是坏消息（即使再多步也改善有限）。对 POMDP 而言，这暗示 Submit-Early 有数据支撑，但也意味着需要更高效的**早期探索策略**——前几步的选择至关重要。
4. **Top-1 probability 与正确性的背离**：top1-top2 gap 和分类确定性呈正相关，但 gap 大并不代表分类正确。对于 POMDP，这意味着仅用不确定度 `u_t` 做 abstention 不够——还需要校准模块来区分"确定的正确"和"确定的错误"。

### 3.8 对 POMDP Reader 的设计启示


| Phase 4 观察               | POMDP 设计启示                                                                 |
| -------------------------- | ------------------------------------------------------------------------------ |
| 信息积累在早期集中         | Submit-Early 有实证基础；早期步的策略质量至关重要                              |
| 分类器在稀疏子图上校准失效 | POMDP 的**Reader 自主裁判**（不再依赖冻结 f_class）是必要方向                  |
| top1_prob 与正确性严重背离 | `u_t`（不确定度）不能单独作为 abstention 信号；需联合置信度校准                |
| 多数类坍缩到少数吸引子     | GSAE 的图嵌入需更强的**判别性**——当前 evidence 不足以区分类别                |
| CE 绝对值极高（~37）       | classifier 的 logits 在稀疏子图上分布极不均匀，需考虑温度缩放或 EDL 损失正则化 |

## 综述：图上主动学习 vs 预算约束图阅读

### 范式对比

| 维度 | 图上主动学习（Active Learning on Graphs） | 本项目（Budgeted Graph Reading） |
|------|------------------------------------------|-------------------------------|
| **预算用途** | 获取节点**标签**（label acquisition） | 揭示节点/边的**信息**（evidence reveal） |
| **决策目标** | 选择哪些节点标注能最大化训练后的模型精度 | 选择揭示哪些节点/边能最大化当前分类精度 |
| **信息流动** | 标注 → 加入训练集 → 重训模型 → 再选择 | 揭示 → 更新观测图 → 再决定 → 最终预测 |
| **时序结构** | 多轮标注-训练迭代 | 单次推理内的多步揭示 |
| **操作对象** | 整个图上的节点 | 局部观测图 G_<b |
| **典型框架** | RL policy / uncertainty score / clustering | 策略 π + 分类器 φ |
| **核心挑战** | 类不平衡、冷启动、探索-利用 | 从 G₀=(V,∅,∅) 冷启动、动作空间设计、预算校准 |

### 关键差异

图上主动学习和本项目虽然都涉及"顺序选择"，但存在**根本性差异**：

```
图上主动学习（AL）：
    选择节点 → 获取标签 → 重新训练模型 → 更多选择
    目标：用最少标注量训练最优分类器
    类比：老师选择最有价值的题目来出考卷

本项目（Budgeted Graph Reading）：
    选择节点/边 → 揭示信息 → 更新观测 → 更多揭示 → 预测
    目标：用最少观测证据做出最优分类
    类比：侦探一步步收集线索来断案
```

> **核心启示**：主动学习的方法论（RL策略、不确定性估计、聚类选择）可以**直接迁移**到项目的揭示策略设计中。差异在于"选择什么"——AL选标签，我们选证据。

## 论文 1：Graph Policy Network（NeurIPS 2020, CCF-A）

| 维度 | 内容 |
|------|------|
| **论文名称** | Graph Policy Network for Transferable Active Learning on Graphs |
| **作者** | Shengding Hu, Zheng Xiong, Meng Qu, Xingdi Yuan, Marc-Alexandre Côté, Zhiyuan Liu, Jian Tang |
| **发表** | **NeurIPS 2020** |
| **期刊等级** | **CCF-A**（人工智能顶级会议） |
| **arXiv** | [2006.13463](https://arxiv.org/abs/2006.13463) |

### 摘要

图神经网络（GNN）在多个领域受到越来越多的关注，但通常需要大量标注数据来训练，而标注成本可能非常高。本文研究图上主动学习——如何在图上高效选择节点标注来降低 GNN 训练成本。我们将问题形式化为图上的顺序决策过程，使用强化学习训练基于 GNN 的策略网络学习最优查询策略。通过在多个全标注源图上联合训练，我们学习一个可迁移的主动学习策略，能直接泛化到未标注的目标图。多个域的实验证明了学习策略在同域和跨域迁移中的有效性。

### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | GNN 训练需要大量标注，但标注成本高；现有主动学习方法不可迁移 |
| **核心贡献** | 首个将 RL + GNN 结合的图上主动学习框架，通过跨图训练实现**策略可迁移性** |
| **方法创新** | MDP 建模节点选择 + 图策略网络（GPN）+ 跨图泛化 |

### 核心思路

```
源图 G_src（全标注）        目标图 G_tgt（未标注）
        │                        │
        ▼                        ▼
   状态编码（GNN）           状态编码（GNN）
        │                        │
        ▼                        ▼
   策略网络 π(a|s)  ──迁移──→  策略网络 π(a|s)
        │                        │
        ▼                        ▼
   RL 训练（最大化标注效率）   直接推理选择节点
```

1. **MDP 建模**：状态 = 当前图 + 已标注节点集合，动作 = 选择下一个标注节点
2. **图策略网络**：GNN 编码图状态 → 输出每个节点的被选概率
3. **跨图泛化**：在源图上用 REINFORCE 训练策略，在目标图上零样本泛化

### 与本项目的对比分析

##### 相似之处

| 维度 | Graph Policy Network | 本项目 |
|------|---------------------|--------|
| **核心范式** | 图上顺序决策——每一步选择一个节点 | 图上顺序决策——每一步选择一个揭示动作 |
| **MDP 建模** | 状态（当前图+已标注集）→ 动作（选节点）→ 奖励（精度提升） | 状态（观测图 G_b）→ 动作（揭示）→ 奖励（信息增益） |
| **策略网络** | GNN 编码图状态，RL 训练策略 | 启发式 → 模仿学习 → RL/端到端策略 |
| **迁移性目标** | 在源图上训练，目标图上零样本泛化 | （未来）跨图泛化揭示策略 |

##### 关键差异

| 维度 | Graph Policy Network | 本项目 |
|------|---------------------|--------|
| **选择目标** | 选择节点获取**标签**（标注） | 选择节点/边获取**证据信息**（揭示）——根本差异 |
| **图可见性** | 完整图结构 + 节点特征可见 | G₀ = (V, ∅, ∅)，逐步揭示 |
| **信息利用** | 标注后重训模型 → 更新策略 | 揭示后更新观测 → 继续决策 |
| **奖励定义** | 标注后的分类精度提升 | 揭示后的信息增益 or 最终分类精度 |
| **跨图迁移** | 核心贡献（源图→目标图） | 当前阶段不涉及（单图推理为主） |

> **启示**：Graph Policy Network 的 MDP 形式化和 RL 训练框架是我们 M4/M5 阶段策略学习的**直接模板**。只需将"选择节点标注"替换为"选择节点揭示"，奖励函数从"标注后的分类精度"改为"揭示后的信息增益"。

## 论文 2：Uncertainty for AL on Graphs（ICML 2024, CCF-A）

| 维度 | 内容 |
|------|------|
| **论文名称** | Uncertainty for Active Learning on Graphs |
| **作者** | Dominik Fuchsgruber, Tom Wollschläger, Bertrand Charpentier, Antonio Oroz, Stephan Günnemann |
| **发表** | **ICML 2024** |
| **期刊等级** | **CCF-A**（机器学习顶级会议） |
| **arXiv** | [2405.01462](https://arxiv.org/abs/2405.01462) |
| **代码** | [github.com/dfuchsgruber/uq-for-al-on-graphs](https://github.com/dfuchsgruber/uq-for-al-on-graphs) |

### 摘要

不确定性采样是一种主动学习策略，目标是通过迭代获取最高不确定度数据点的标签来提高机器学习模型的数据效率。虽然它在独立数据上已证明有效，但在图数据上的适用性仍未被充分探索。本文提出了首个图节点分类的不确定性采样广泛研究：(1) 我们基准测试了预测不确定性以外的不确定性采样，揭示了与其他主动学习策略之间的显著性能差距；(2) 我们基于数据生成过程开发了真实贝叶斯不确定性估计，并证明了其在引导不确定性采样至最优查询方面的有效性；(3) 基于此分析，我们将不确定性建模中的缺陷与现有方法相关联。

### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 不确定性采样在图上为什么效果不好？如何设计图上的真贝叶斯不确定性？ |
| **核心贡献** | 首次系统研究图上的不确定性采样——揭示预测不确定性 ≠ 最优查询，提出基于数据生成过程的地面真值贝叶斯不确定性估计 |

### 核心思路

```
传统不确定性采样：
    选择预测熵最大的节点 → 标注 → 重训
    问题：图结构使不确定性估计有偏

本文方法：
    建模数据生成过程 → 贝叶斯后验 → 认知不确定性
    ↓
    选择认知不确定性最大的节点 = 最优查询
    （最大化分类器对正确预测的信心增益）
```

1. **系统性基准**：对比多种不确定性度量（预测熵、BALD、MC Dropout 等）在图上的表现
2. **地面真值设计**：构造已知数据生成过程的合成数据，计算真贝叶斯不确定性
3. **近似方法**：基于分析结果设计实用的图上不确定性近似估计器

### 与本项目的对比分析

##### 相似之处

| 维度 | Uncertainty for AL | 本项目 |
|------|-------------------|--------|
| **不确定性驱动** | 选择不确定性最高的节点标注 | （可借鉴）选择信息不确定性最高的节点揭示 |
| **理论严谨** | 贝叶斯推断 + 认知不确定性 | （可借鉴）信息论 + 决策论 |
| **最优查询** | 认知不确定性最大 = 分类器信心增益最大 | 边际信息增益最大 = 分类精度提升最大 |

##### 关键差异

| 维度 | Uncertainty for AL | 本项目 |
|------|-------------------|--------|
| **不确定性焦点** | 对**标签预测**的不确定性（epistemic） | 对**信息获取价值**的不确定性（信息论）——根本差异 |
| **选择策略** | greedy 逐个选择最高不确定性节点 | 可组合原子动作 + 显式预算约束 |
| **图可见性** | 完整图特征可见（只缺标签） | G₀ = (V, ∅, ∅)（特征和结构都缺） |
| **操作粒度** | 单个节点 | 原子动作 → 复合揭示（节点/边/邻域/游走） |

> **启示**：这篇文章的不确定性分析直接指导我们的**揭示价值函数设计**。在 M4 阶段，我们可以将"认知不确定性最高的节点"作为"最值得揭示的信息"的近似——不确定性采样 → 信息揭示优先级。

## 论文 3：SCARCE（ICLR 2024, CCF-A）

| 维度 | 内容 |
|------|------|
| **论文名称** | Structural Fairness-aware Active Learning for Graph Neural Networks |
| **作者** | Haoyu Han, Xiaorui Liu, Li Ma, MohamadAli Torkamani, Hui Liu, Jiliang Tang, Makoto Yamada |
| **发表** | **ICLR 2024** |
| **期刊等级** | **CCF-A**（表征学习顶级会议） |

### 摘要

GNN 在半监督节点分类中取得了显著成就，但其效能往往依赖于获取高质量的标注节点。虽然主动学习被广泛用于识别和标注高质量样本，但图数据由于其内在结构使节点非独立同分布，带来了独特挑战。此外，标注节点的位置引入偏差——靠近已标注节点的节点通常表现更好。本文提出统一优化框架 SCARCE，更好地利用图结构并减轻主动学习中的结构偏差。大量实验表明，该方法不仅提升了 GNN 性能，还促进了更公平的结果。

### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 图上节点非 i.i.d. + 标注节点位置引入**结构偏差**——靠近已标注节点被不公平地优待 |
| **核心贡献** | 首个将**结构公平性**（structural fairness）引入图主动学习的统一优化框架 |

### 核心思路

```
标准主动学习：
    选择"最有信息量"的节点 → 偏袒靠近已标注集的结构位置

SCARCE：
    max 信息量 + λ·公平性正则
    ├─ 信息量：节点对模型预测的边际贡献
    └─ 公平性：节点在图中的结构位置应在选择中均匀分布
```

### 与本项目的对比分析

##### 相似之处

| 维度 | SCARCE | 本项目 |
|------|--------|--------|
| **公平/多样性意识** | 避免标注节点集中于某个结构区域 | 避免揭示动作集中于某个密集子图 |
| **优化框架** | 信息量 + 公平正则（统一优化） | 预算约束下的策略优化 |

##### 关键差异

| 维度 | SCARCE | 本项目 |
|------|--------|--------|
| **公平性定义** | 标注节点的**结构位置公平**（不同区域被平等标注） | 揭示动作的**空间覆盖公平**（不同区域被平等揭示）——根本差异 |
| **公平性来源** | 标注偏向靠近已标注节点的位置 | 邻域揭示动作天然倾向于稠密子图 |
| **实现方式** | 优化目标中的正则项 | 可通过多样性奖励或约束实现 |
| **图可见性** | 完整图可见 | 逐步揭示 |

> **启示**：SCARCE 的结构公平性概念可以直接转化为揭示策略的**多样性约束**——避免 B 个预算全部花在同一个稠密子图上，鼓励策略探索图的不同部分。

## 论文 4：GRAIN（VLDB 2021, CCF-A）

| 维度 | 内容 |
|------|------|
| **论文名称** | GRAIN: Improving Data Efficiency of Graph Neural Networks via Diversified Influence Maximization |
| **作者** | Wentao Zhang, Zhi Yang, Yexin Wang, Yu Shen, Yang Li, Liang Wang, Bin Cui |
| **发表** | **VLDB 2021**（Proceedings of the VLDB Endowment） |
| **期刊等级** | **CCF-A**（数据库顶级会议） |
| **arXiv** | [2108.00219](https://arxiv.org/abs/2108.00219) |

### 摘要

GNN 的性能严重依赖于充足的标注数据，但标注成本高。本文提出 GRAIN，通过多样化影响力最大化来提升 GNN 的数据效率。GRAIN 将数据选择问题转化为图上的影响力最大化问题——选择一组节点使得它们的"影响力"（对未标注节点预测的改善）最大化，同时引入多样性约束避免冗余。在多个公共数据集上的实验表明，GRAIN 显著提升了数据选择（包括主动学习和核心集选择）的性能和效率。

### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 如何选择训练节点子集使 GNN 性能最大化？传统主动学习忽略节点间的**影响力传播** |
| **核心贡献** | 首次将**影响力最大化**（IM）与**多样性约束**结合用于 GNN 数据选择 |

### 核心思路

```
影响力最大化视角：
    选择种子节点 S → 标签信息沿图传播 → 影响覆盖
    
GRAIN：
    节点 v 的"影响力" = 标注 v 后，其邻居节点的预测质量改善
    ↓
    选择 S：max Σ 影响力(v) - λ·冗余(S)
    ├─ 影响力：基于 GNN 的标签传播
    └─ 多样性：避免选到高度重叠的"影响域"
```

### 与本项目的对比分析

##### 相似之处

| 维度 | GRAIN | 本项目 |
|------|-------|--------|
| **选择机制** | 从图中选最有"影响力"的节点 | 从图中选最有"信息量"的节点/边 |
| **多样性约束** | 避免冗余选择（影响力域重叠） | 避免重复揭示相同区域 |
| **传播视角** | 标注影响力沿图传播 | 揭示的信息沿图传播到邻居节点 |

##### 关键差异

| 维度 | GRAIN | 本项目 |
|------|-------|--------|
| **选择目标** | 训练节点标签（一次选择，固定集合） | 揭示证据信息（顺序选择，每步更新）——根本差异 |
| **影响力定义** | 标注节点对邻居预测精度的改善 | 揭示节点对观测图信息量的增加 |
| **时序性** | 一次性选择节点集合 | 顺序揭示——每步观测影响下一步决策 |
| **图可见性** | 完整图可见 | 逐步揭示 |

> **启示**：GRAIN 的影响力最大化框架可以转化为**揭示动作的价值度量**——"揭示节点 v 后，v 的邻居节点的先验不确定性降低了多少？"这个"边际影响力"是 M4 轨迹评分的核心指标候选。

## 论文 5：ALLIE（WWW 2022, CCF-A）

| 维度 | 内容 |
|------|------|
| **论文名称** | ALLIE: Active Learning on Large-scale Imbalanced Graphs |
| **作者** | Limeng Cui, Xianfeng Tang, Sumeet Katariya, Nikhil Rao, Pallav Agrawal, Karthik Subbian, Dongwon Lee |
| **发表** | **WWW 2022**（The ACM Web Conference） |

### 摘要

许多基于分数的主动学习方法已成功应用于图数据，旨在基于预定义分数函数减少标注数量并提升 GNN 性能。然而，这些算法难以学习与奖励成正比的策略分布，且探索能力有限。本文创新性地将图主动学习问题形式化为**生成过程**，提出 GFlowGNN——通过生成流网络（GFlowNet）以与奖励函数精确成正比的概率生成多样化的标注序列。进一步提出流节点和流特征的概念来高效建模图。大量实验表明，该方法具有良好的探索能力和可迁移性，优于多种现有方法。

| 维度 | 内容 |

    训练：使 P_F 生成的轨迹分布 ∝ R(x)

```

| 维度 | GFlowGNN | 本项目 |

| **图可见性** | 完整图可见 | 逐步揭示 |
| **奖励定义** | 最终标注集的分类性能 | 揭示路径的信息增益 or 最终分类精度 |

## 论文 7：GraphCBAL（CIKM 2024, CCF-B / KBS 2025, SCI）

| 维度 | 内容 |
|------|------|
| **论文名称** | GraphCBAL: Class-Balanced Active Learning for Graph Neural Networks via Reinforcement Learning |
| **作者** | Chengcheng Yu (Shanghai Polytechnic), Jiapeng Zhu, Xiang Li (East China Normal University) |
| **发表** | **CIKM 2024**（CCF-B）→ 扩展版 **Knowledge-Based Systems, Vol. 341, 2025**（SCI 一区） |

### 摘要

GNN 在节点分类、链接预测和图分类等任务中取得了显著成功。主动学习旨在查询最有价值的未标注样本以最大化 GNN 性能同时降低成本。然而，大多数 GNN 强化主动学习算法可能导致高度不平衡的类别分布。本文提出 GraphCBAL——一个类别平衡的强化主动学习框架，学习最优策略以获取**类别平衡且信息丰富**的节点进行标注。通过设计类别平衡感知状态和权衡模型性能与类别平衡的奖励函数，使用 A2C 算法学习最优策略。还升级为 GraphCBAL++ 引入惩罚机制。多数据集实验证明了该方法的优越性。

| 维度 | 内容 |
|------|------|
| **核心问题** | RL 主动学习方法在追求性能最大化时**不考虑类别平衡**，导致标注集偏差 |

    └─ Balance_gain：各类标注比例趋近均匀
    
策略：A2C (Advantage Actor-Critic)
    Actor：输出节点选择概率分布
    Critic：估计当前状态的价值
```

## 论文 8：LSCALE（ECML-PKDD 2022, CCF-B）

| 维度 | 内容 |
|------|------|
| **论文名称** | LSCALE: Latent Space Clustering-Based Active Learning for Node Classification |
| **作者** | Juncheng Liu, Yiwei Wang, Bryan Hooi, Renchi Yang, Xiaokui Xiao |
| **发表** | **ECML-PKDD 2022** |
| **期刊等级** | **CCF-B**（欧洲机器学习重要会议） |
| **arXiv** | [2012.07065](https://arxiv.org/abs/2012.07065) |

### 摘要

图上的节点分类在许多实际领域中是重要任务，通常需要标注数据来训练，而标注在实践中可能困难或昂贵。本文提出基于潜在空间聚类的主动学习框架 LSCALE，充分利用标注和未标注节点的表示能力。具体来说，我们的框架使用基于无监督特征和监督特征动态组合的潜在空间上的 K-Medoids 聚类算法来选择标注节点。此外，我们设计了增量聚类模块以避免不同步骤中选择的节点之间的冗余。在五个数据集上的大量实验表明，LSCALE 始终显著优于最先进的方法。

### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 现有图主动学习方法**未充分利用未标注节点**的表示能力 |
| **核心贡献** | 动态融合无监督特征（DGI）+ 监督特征（GCN）的潜在空间聚类选择框架 |

### 核心思路

```
特征提取：
    ├─ 无监督：Deep Graph Infomax → z_unsup
    └─ 监督（少量标注）：GCN → z_sup
    
动态融合：
    Z = α(t)·z_unsup + (1-α(t))·z_sup
    α(t) 随时间递减（标注越多，监督特征越可靠）

增量聚类选择：
    K-Medoids(Z) → 选聚类中心
    增量约束：新中心远离已选节点（避免冗余）
```

### 与本项目的对比分析

##### 相似之处

| 维度 | LSCALE | 本项目 |
|------|--------|--------|
| **聚类选择** | K-Medoids 聚类 → 选中心节点 | 度中心性/BFS 等结构启发式 |
| **冗余避免** | 增量聚类避免选到重复区域 | 已揭示节点不再消耗预算（天然冗余避免） |
| **冷启动** | 初始无监督特征不可靠 → 等价随机 | 方案 A 的 G₀ 冷启动同样面临盲选问题 |

##### 关键差异

| 维度 | LSCALE | 本项目 |
|------|--------|--------|
| **特征利用** | 无监督(DGI) + 监督(GCN)特征动态融合 | 逐步揭示的特征（从无到有）——根本差异 |
| **选择目标** | 聚类中心节点（标注） | 多种启发式动作（揭示节点/边/邻域） |
| **特征来源** | 所有节点特征已知（无监督预训练） | 仅揭示过的节点特征已知 |
| **图可见性** | 完整图特征 + 结构可见 | 逐步揭示 |

> **启示**：LSCALE 的**增量聚类**思路可以直接转化为我们方案 A 的改进——在 G₀ 无任何信息时，可以先用少量预算做"探索性揭示"（随机选几个种子），然后基于已揭示的信息做聚类选择。

| **发表** | **ACM Transactions on Knowledge Discovery from Data（TKDD）**, 2024 |
| **期刊等级** | **CCF-B**（数据挖掘重要期刊） |

### 摘要

GNN 的强大能力依赖于大量标注训练数据，但获取标注在许多情况下成本高昂。图主动学习（GAL）被提出来降低标注成本，但现有方法主要关注固定类别下的标注效率提升，无法处理新类别的出现。本文将这个问题称为开放世界图主动学习（OWGAL），并提出同名框架。关键是在统一框架中同时识别**新类别节点和信息丰富节点**。OWGAL 使用原型学习和标签传播分别在表示空间和拓扑空间中为节点分配高不确定性分数，加权采样进一步通过同时考虑节点和类别重要性来抑制不重要类别的影响。在四个大规模数据集上，Macro-F1 提升 5.97% 至 16.57%。

| 维度 | 内容 |
|------|------|
| **核心问题** | 开放世界场景——新类别不断涌现，主动学习需要同时识别"已有类别的信息节点"和"新类别节点" |

### 核心思路

```
双空间不确定性：
    ├─ 表示空间：原型学习 → 距已有的原型远的节点 = 高不确定性（可能是新类）
    └─ 拓扑空间：标签传播 → 邻居无标签的节点 = 高不确定性

加权采样：
    节点权重 = w_node × w_class
    ├─ w_node：节点不确定性
    └─ w_class：类别重要性（已有类别 vs 潜在新类别）
```

### 与本项目的对比分析

##### 相似之处

| 维度 | OWGAL | 本项目 |
|------|-------|--------|
| **双空间驱动** | 表示空间 + 拓扑空间的不确定性 | 拓扑不确定性（未揭示区域）+ 特征不确定性（未揭示特征） |

##### 关键差异

| 维度 | OWGAL | 本项目 |
|------|-------|--------|

| **不确定性类型** | 对新类别的检测不确定性 | 对观测图信息不完备的不确定性 |
| **双空间** | 原型学习(表示空间) + 标签传播(拓扑空间) | 基于观测图 G_b 的决策（拓扑+特征逐步揭晓） |
| **图可见性** | 完整图可见 | 逐步揭示 |
| **未来方向** | — | M5 后可扩展为开放世界：揭示动作也用于发现"是否需要更多证据" |

> **启示**：OWGAL 的"双空间不确定性"设计可以转化为揭示策略的双重驱动力——拓扑不确定性（图的哪些区域还没看过）+ 特征不确定性（已看到的部分中哪些节点特征最关键）。

## 论文 10：STAL（Data Mining & Knowledge Discovery, SCI）

| 维度 | 内容 |

| **论文名称** | Improving Graph Neural Networks by Combining Active Learning with Self-Training |
| **作者** | Georgios Katsimpras, Georgios Paliouras |
| **发表** | **Data Mining and Knowledge Discovery（DMKD）**, 2024, Vol.38, pp.110–127 |
| **期刊等级** | **SCI / CCF-B**（数据挖掘权威期刊） |

### 摘要

本文提出 STAL 框架，结合主动学习和自训练来利用未标注图数据改进 GNN 的节点标注。GNN 在有充足标注数据时表现良好，但标注数据往往稀缺。主动学习和自训练是解决此问题的两种常用方法，本文首次在 GNN 训练场景中研究它们的组合。具体来说，STAL 首先使用主动学习选择高不确定性的未标注节点进行人工标注，然后在每次主动标注迭代中通过自训练扩展标签集——将高置信度的伪标签自动加入训练集。该过程迭代进行，在有限标注数据下获得良好分类器。

### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 标注数据稀缺——现有方法只用一个范式（AL 或自训练），未结合 |
| **核心贡献** | 首次将主动学习 + 自训练结合用于 GNN：AL 选高不确定性节点（人工标注），自训练选高置信度节点（伪标签） |

### 核心思路

```
迭代过程（每轮）：
    
    ┌─ 主动学习 ───────────────────┐
    │ 选择高不确定性节点 → 人工标注  │
    │ → 加入训练集 L                 │
    └──────────────────────────────┘
                │
    ┌─ 自训练 ─────────────────────┐
    │ 在当前模型下预测未标注节点      │
    │ 选高置信度节点 → 伪标签       │
    │ → 加入训练集 L                 │
    └──────────────────────────────┘
                │
                ▼
        重训 GNN → 下一轮
```

### 与本项目的对比分析

##### 相似之处

| 维度 | STAL | 本项目 |
|------|------|--------|
| **混合策略** | 高不确定性→人工标注 + 高置信度→自动标注 | 高不确定性→付费揭示 + 高置信度→免费推理 |
| **迭代思想** | 标注与自训练交替进行 | 揭示与推理交替进行 |
| **效率目标** | 用最少人工标注 + 最多自动标注达到最优 | 用最少付费揭示 + 最多推理完成最优分类 |

##### 关键差异

| 维度 | STAL | 本项目 |
|------|------|--------|

## 论文 11：GALMI（ESWA 2024, SCI）

| 维度 | 内容 |
|------|------|
| **论文名称** | Adaptive Graph Active Learning with Mutual Information via Policy Learning |
| **作者** | Yang Huang, Yueyang Pi, Yiqing Shi, Wenzhong Guo, Shiping Wang (Fuzhou University) |

### 摘要

本文提出 GALMI——一种基于强化学习的自适应图主动学习框架。将图主动学习建模为**马尔可夫决策过程（MDP）**：状态由基于互信息（MI）的节点表示构成，同时捕获图结构和节点属性；动作是选择下一个节点标注；奖励是 GCN 在验证集上的分类性能提升。策略网络通过 RL 训练，在预算约束下学习自适应的节点选择策略。在多数据集上的实验证明 GALMI 优于现有的图主动学习方法。

### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 现有方法使用固定启发式或忽略图结构的动态变化——需要自适应策略 |
| **核心贡献** | MDP 模型 + 互信息状态表示 + RL 策略学习，首次将 MI 引入图主动学习的状态设计 |

### 核心思路

```
GALMI 三阶段架构:

  阶段 1: MI 计算
    对每对节点 (v_i, v_j) 计算互信息 MI(v_i, v_j)
    MI 捕获：节点属性相似度 + 图结构邻近度
    
  阶段 2: MDP 建模
    状态 s_t = [已标注节点的 MI 表示, 剩余预算]
    动作 a_t = 选择下一个标注节点
    奖励 r_t = GCN 验证精度提升
    
  阶段 3: RL 训练
    策略网络 π_θ(a|s) 通过 Policy Gradient 训练
    最大化累积奖励 = 预算内的分类性能
```

1. **互信息状态**：MI 同时编码节点属性信息和图结构信息，比单纯用 GNN embedding 或 PageRank 更丰富
2. **自适应策略**：策略网络根据当前状态动态调整选择——标注集扩大后策略自动变化
3. **预算感知**：剩余预算作为状态的一部分，策略学会在预算紧张时优先关键节点

### 与本项目的对比分析

##### 相似之处

| 维度 | GALMI | 本项目 |
|------|-------|--------|
| **MDP 建模** | 顺序节点选择 → 状态 → 动作 → 奖励 | 顺序节点揭示 → 状态(G_b) → 动作(reveal) → 奖励(accuracy) |
| **RL 训练** | Policy Gradient 训练自适应策略 | BC → RL 两阶段训练 |
| **预算约束** | 固定标注预算 B | 固定揭示预算 B |
| **信息论驱动** | 互信息（MI）作为状态表示 | 信息增益作为揭示动作的 value |
| **最终目标** | 最大化 GCN 分类精度 | 最大化 classifier 分类精度 |

##### 关键差异

| 维度 | GALMI | 本项目 |
|------|-------|--------|
| **任务** | 节点分类（标注节点 → 训练 GCN → 预测剩余节点） | 图级分类（揭示节点 → 构建子图 → 预测该图标签） |

## 论文 12：ReiPool（TKDE 2024, CCF-A）

| 维度 | 内容 |
|------|------|
| **论文名称** | ReiPool: Reinforced Pooling Graph Neural Networks for Graph-Level Representation Learning |
| **作者** | Xuexiong Luo, Sheng Zhang, Jia Wu, et al. (Macquarie University) |

| **代码** | [github.com/zhejiangzhuque/ReiPool](https://github.com/zhejiangzhuque/ReiPool) |

### 摘要

图池化（graph pooling）是图级分类中的关键操作，通过粗化图来学习图级表示。现有方法机械地固定池化层数和粗化比例，忽略了不同图的结构差异。本文提出 ReiPool——使用**多智能体强化学习**自适应地为每张图决定池化策略。Feature-agent 控制粗化节点特征的融合方式；Depth-agent 自适应决定该图的粗化层数。结合混合图粗化模块（同时压缩一跳和星型结构）和图级对比学习，ReiPool 在多个基准上超越现有池化方法。

### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 图池化层数/粗化比例应是**图自适应的**——不同图需要不同程度的粗化 |
| **核心贡献** | 多智能体 RL（feature-agent + depth-agent）+ 混合粗化 + 图级对比学习 |

### 核心思路

```
ReiPool 架构:

  输入图 G
      │
      ▼
  ┌─────────────────────────────────┐
  │  混合粗化模块                    │
  │  ├─ 一跳结构粗化 (first-order)   │
  │  └─ 星型结构粗化 (star)          │
  └─────────────────────────────────┘
      │
      ▼
  ┌─────────────────────────────────┐
  │  RL Agent 1: Feature-agent      │
  │  控制粗化后节点特征的融合比例     │
  └─────────────────────────────────┘
      │
      ▼
  ┌─────────────────────────────────┐
  │  RL Agent 2: Depth-agent        │
  │  决定是否继续粗化 or 停止         │
  └─────────────────────────────────┘
      │
      ▼
  读出 → 图级表示 → 分类
```

1. **混合粗化**：同时考虑一跳邻居和星型结构（中心节点+叶节点），比单纯基于聚类的池化保留更多拓扑信息
2. **双 RL Agent**：feature-agent（连续动作）和 depth-agent（离散动作）协同决策，端到端训练
3. **图级对比学习**：粗化图与输入图之间的互信息最大化，确保粗化不丢失全局信息

### 与本项目的对比分析

##### 相似之处

| 维度 | ReiPool | 本项目 |
|------|---------|--------|
| **任务** | 图级分类 | 图级分类 |
| **决策粒度** | 每图自适应的粗化策略 | 每图自适应的揭示策略 |
| **RL 框架** | 多智能体 RL 决定保留哪些节点 | （未来）RL 决定揭示哪些节点 |
| **信息选择** | 选择保留哪些节点（粗化 = 删除节点） | 选择揭示哪些节点（揭示 = 添加节点到观测）——**对偶问题** |
| **自适应** | 不同图不同粗化层数 | 不同图不同揭示路径 |

##### 关键差异

| 维度 | ReiPool | 本项目 |
|------|---------|--------|
| **操作方向** | **删除**节点（粗化，信息压缩） | **添加**节点（揭示，信息扩展）——对偶但相反 |
| **图可见性** | 完整图可见 | G₀ = (V, ∅, ∅)，逐步揭示 |
| **决策时机** | 全图已知后做粗化（后验压缩） | 图未知时做揭示（先验探索） |
| **信息状态** | 从多到少（压缩） | 从少到多（揭示） |
| **RL 用途** | 学习"粗化多少层" | 学习"揭示哪个节点" |

> **启示**：ReiPool 与本研究形成精妙的**对偶关系**——ReiPool 在全图上"删除不重要的节点"，我们在未知图上"添加重要节点"。两者都在回答"哪些节点对图级分类最有用"。ReiPool 的 RL 架构（双 agent 协调）和"不同图自适应不同策略"的理念可直接指导 M5 RL 阶段的设计。此外，ReiPool 的混合粗化（一跳+星型）可以反过来启发我们的**混合揭示动作**——不仅揭示单个节点，还可揭示"星型邻域"（中心节点+一跳邻居）。

## 论文 14：SelectiveNet（ICML 2019, CCF-A）

| 维度 | 内容 |
|------|------|
| **论文名称** | SelectiveNet: A Deep Neural Network with an Integrated Reject Option |
| **作者** | Yonatan Geifman, Ran El-Yaniv (Technion) |
| **发表** | **ICML 2019** |
| **期刊等级** | **CCF-A**（机器学习顶级会议） |
| **代码** | [github.com/geifmany/SelectiveNet](https://github.com/geifmany/SelectiveNet) |

### 摘要

选择性分类——模型可以选择对不确定的样本"拒绝回答"——是风险敏感应用中的重要能力。本文提出 SelectiveNet，首个在单个神经网络中集成拒绝选项的深度架构。三头输出（预测头、选择头、辅助头）联合优化：选择性风险（在覆盖样本上的分类误差）、覆盖度（选择回答的比例）和辅助 loss。训练使用批量梯度下降端到端完成，无需后处理阈值调校。在 CIFAR-10/100、SVHN、ImageNet 上的实验证明了方法在覆盖度-准确率权衡上的优势。

### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 如何将"拒绝回答"能力集成到深度模型中，端到端训练而非事后设阈值 |
| **核心贡献** | 三头架构（预测+选择+辅助）+ 选择性风险优化 + 端到端训练 |

### 核心思路

```
三头架构:
  共享躯干（CNN/ResNet）
      │
      ├─ Prediction Head:  f(x) → ŷ      标准分类
      ├─ Selection Head:   g(x) → [0,1]  是否回答（概率）
      └─ Auxiliary Head:   h(x) → ŷ_aux  辅助预测（仅用于训练）

选择性风险:
  R_selective = Σ[g(x_i) · L(f(x_i), y_i)] / Σ g(x_i)
  
覆盖度约束:
  Φ(g) = max(0, c_target - avg(g(x)))
  c_target = 期望覆盖度（例如 0.7 = 至少 70% 样本要回答）

总 loss = R_selective + λ · Φ(g)
```

### 与本项目的对比分析

##### 相似之处

| 维度 | SelectiveNet | 本项目 Submit-Early |
|------|-------------|-------------------|
| **核心问题** | 模型何时说"我不知道" | Reader 何时说"我已经确定了" |
| **决策机制** | Selection Head 输出是否回答 | SubmitHead 输出是否提交 |
| **自适应** | 不同样本不同处理（答 or 拒） | 不同图不同步数（提 or 继续） |
| **端到端** | 三头联合训练 | 联合 RL 训练 |

##### 关键差异

| 维度 | SelectiveNet | 本项目 |
|------|-------------|--------|
| **任务** | 图像分类（固定输入） | 图阅读（序列累积输入） |
| **时序性** | 单次决策（答/拒） | 每步决策（提交/揭示） |
| **信息变化** | 输入固定 | 每步揭示后子图扩展 |
| **覆盖目标** | 人为设 c_target | 预算 B 天然上限 |

> **启示**：SelectiveNet 是 SubmitHead 的**直接理论模板**——"选择不回答"就是"选择不提交"。不同在于 SelectiveNet 是单次决策（看完整输入一次判断），SubmitHead 是序列决策（每步判断是否该交了）。SelectiveNet 的三头联合训练 + 选择性风险优化是 SubmitHead 训练的参考范式。

##### 相似之处

| 维度 | JEI-DNN | 本项目 Submit-Early |
|------|---------|-------------------|
| 核心原则 | 退出决策与预测质量**联合训练** | SubmitHead 与 Reader **联合 RL 训练** |
| 决策依赖 | 中间表示 + 进度 | 信念状态 + 预算进度 |
| 自适应 | 不同样本不同深度 | 不同图不同步数 |
| 校准意识 | ECE（期望校准误差）关键指标 | p_submit 的信度校准 |

##### 关键差异

| 维度 | JEI-DNN | 本项目 |
|------|---------|--------|
| 计算粒度 | 网络层（0, 1, ..., L 层后退出） | 揭示节点（1, 2, ..., B 步后提交）——不同粒度 |
| 信息积累 | 逐层抽象 | 逐节点揭示 |
| 动作空间 | 退出 or 继续 | 提交 or 揭示哪个节点 |

> **启示**：JEI-DNN 验证了"联合训练退出决策优于单独设阈值"这一核心假设——直接支撑了 SubmitHead 联合 RL 训练的设计选择（而非 Phase 2.5 单独训完冻结）。

## 论文 16：EERO（2024, Preprint）

| 维度 | 内容 |
|------|------|
| **论文名称** | EERO: Early Exit with Reject Option under a Fixed Computational Budget |
| **作者** | Valade, Hebiri, Gay |
| **发表** | **Preprint（arXiv）**, Feb 2024 |
| **期刊等级** | 预印本（待投） |

### 摘要

本文将早期退出的问题重新形式化为"固定计算预算下的分类拒绝选项"问题。不同于传统关注准确率-计算量权衡，EERO 在**给定总计算预算**（GFlops）的前提下优化分类性能。通过指数权重聚合校准退出头概率，并通过 CDF 阈值控制聚合决策。在 ResNet-18、ConvNext、MSDNet 上的实验证明了方法在预算约束下的优势。

### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 在固定总计算预算下如何最优分配样本的计算量？ |
| **核心贡献** | 预算约束形式化 + 指数权重聚合校准 + CDF 阈值退出规则 |

### 核心思路

```
固定计算预算 B_compute:

  传统 early-exit:  每样本独立的 acc-vs-cost 权衡
  EERO:             总计算 ≤ B_compute 约束下最大化总体准确率

  关键: 总预算在样本间的最优分配
        → 容易样本用浅层（省计算）
        → 难样本用深层（花预算）
        → 总计算约束下整体最优
```

### 与本项目的对比分析

##### 相似之处（极高）

| 维度 | EERO | 本项目 Submit-Early |
|------|------|-------------------|
| **核心约束** | 固定总计算预算（GFlops） | 固定揭示预算（B 步） |
| **决策问题** | 每样本分配多少计算 | 每图分配多少步 |
| **优化目标** | 预算内最大化总体准确率 | 预算内最大化分类准确率 |
| **自适应** | 不同样本不同计算量 | 不同图不同步数 |

这是本项目中与 EERO **问题形式化最对齐的现有工作**——把"计算预算"换成"揭示预算"即可。

##### 关键差异

| 维度 | EERO | 本项目 |
|------|------|--------|
| 信息积累 | 深度轴（层间） | 广度轴（图内空间） |
| 不可逆性 | 已计算层的表示可复用 | 已揭示节点不可逆 |
| 动作 | 退出（终止）or 继续 | 提交（终止）or 揭示哪个节点 |

> **启示**：EERO 的"固定预算下最优样本间计算分配"问题，实质就是 Submit-Early 的"固定预算下最优图间步数分配"。EERO 的指数权重聚合和 CDF 阈值方法可以直接指导评估阶段的 $\tau$ 调优："如何在总预算不变的情况下，通过让一部分图提前交卷、省下的步数分配给其他图，提升总体准确率？"

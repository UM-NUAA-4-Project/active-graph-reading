## 类别一：图理性化——内禀可解释子图选择

> 这一类别是本项目最直接的相关工作。图理性化（Graph Rationalization）的目标是从输入图中提取**最小充分子图（rationale）**来支撑分类预测，与本项目的"预算内选择性揭示图证据"在核心直觉上高度一致。关键区别：图理性化方法通常假设完整图可见，而本项目从 G₀ = (V, ∅, ∅) 开始逐步揭示。

### 论文 1：DIR — 为图神经网络发现不变理性

| 维度 | 内容 |
|------|------|
| **论文名称** | Discovering Invariant Rationales for Graph Neural Networks |
| **作者** | Ying-Xin Wu, Xiang Wang, An Zhang, Xiangnan He, Tat-Seng Chua |
| **发表** | **ICLR 2022** |
| **期刊等级** | **CCF-A**（国际机器学习顶级会议） |
| **arXiv** | [2201.12872](https://arxiv.org/abs/2201.12872) |
| **代码** | [github.com/Wuyxin/DIR-GNN](https://github.com/Wuyxin/DIR-GNN) |

#### 摘要

图神经网络（GNN）的内禀可解释性旨在找到输入图特征的一个小子集——理性（rationale）——来指导模型预测。然而，主流的理性化模型常常依赖数据偏差（尤其是捷径特征）来构建理性并做出预测，而未探及因果关键模式。这些数据偏差在训练分布之外容易发生变化，导致模型在分布外（OOD）数据上的可解释性和预测性能大幅下降。本文提出一种发现不变理性（DIR）的新策略：在训练分布上执行干预以创建多个干预分布，然后逼近跨不同分布不变且能过滤掉不稳定虚假模式的因果理性。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | GNN 理性化模型倾向于利用训练数据中的**虚假相关性（spurious correlations）**而非学习真正因果的模式，导致 OOD 场景下可解释性和预测性能崩溃 |
| **核心贡献** | 提出 DIR 策略——通过**因果干预**（intervention）创建多分布环境，发现跨环境不变的因果理性，过滤分布相关的虚假模式 |
| **创新点** | 首次将因果不变性原理引入 GNN 可解释性，在同一框架内同时实现可解释性和 OOD 泛化 |

#### 核心思路

```
训练数据 D
    │
    ├─ 干预1 → 干预分布1
    ├─ 干预2 → 干预分布2
    └─ 干预K → 干预分布K
            │
            ▼
    寻找跨K个分布都"稳定预测"的子图 → 因果理性
    在不同分布间"不稳定"的子图 → 虚假模式（丢弃）
```

1. **多环境创建**：对训练分布施加结构/特征层面的干预，生成多个不同的"环境"
2. **不变理性搜索**：在多个环境中寻找预测稳定的子图（因果理性），排除环境依赖的虚假模式
3. **端到端训练**：理性提取器 + 分类器联合优化

#### 与本项目的对比分析

##### 相似之处

| 维度 | DIR | 本项目 |
|------|-----|--------|
| **核心直觉** | 寻找对分类最关键的子图（理性） | 在预算内揭示对分类最关键的证据 |
| **优化目标** | 最大化子图与标签的因果关联 | 最大化预算内的预测精度 |
| **可解释性** | 内禀可解释（理性即解释） | 揭示路径即解释（"模型读了哪里"） |

##### 关键差异

| 维度 | DIR | 本项目 |
|------|-----|--------|
| **图可见性** | 完整图 G 始终可见 | G₀ = (V, ∅, ∅)，逐步揭示（根本差异） |
| **预算模型** | 无显式预算（稀疏正则做软约束） | **显式整数预算 B + 原子成本单位** |
| **选择粒度** | 子图级（一次选出一个连通子图） | 原子级 → 复合动作（节点/边/邻域/游走） |
| **时序性** | 单步选择（无顺序揭示过程） | 多步顺序揭示（每步依赖前步观测） |
| **动机框架** | 因果推断 + OOD 泛化 | LLM agent 上下文检索 + 证据获取 |

> **启示**：DIR 的"寻找不变因果子图"与我们"在预算内学会往哪里看"是互补目标——DIR 找的是"最终应该关注什么"，我们关注的是"在看不到全景时怎么一步步找"。M4/M5 阶段可将 DIR 的因果理性作为"教师策略"的 oracle 上界。

### 论文 2：GSAT — 通过随机注意力机制实现可解释且可泛化的图学习

| 维度 | 内容 |
|------|------|
| **论文名称** | Interpretable and Generalizable Graph Learning via Stochastic Attention Mechanism |
| **作者** | Siqi Miao, Miaoyuan Liu, Pan Li |
| **发表** | **ICML 2022** |
| **期刊等级** | **CCF-A**（国际机器学习顶级会议） |
| **arXiv** | [2201.12987](https://arxiv.org/abs/2201.12987) |
| **代码** | [github.com/Graph-COM/GSAT](https://github.com/Graph-COM/GSAT) |

#### 摘要

可解释图学习对许多科学应用至关重要。以往工作主要使用事后方法来解释预训练模型，认为内禀可解释模型会牺牲预测精度。然而，事后方法往往无法提供稳定解释，且可能提取与任务虚假相关的特征。本文提出图随机注意力（GSAT）：从信息瓶颈原理出发，向注意力权重中注入随机性以阻断任务无关图组件的信息流，同时学习减少随机性以选择任务相关子图用于解释。所选子图在一定假设下**可证明不包含与任务虚假相关的模式**。在 8 个数据集上，GSAT 的解释 AUC 提升高达 20%↑，预测精度提升 5%↑。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 事后可解释方法不稳定且易提取虚假特征；内禀可解释模型被认为会牺牲精度 |
| **核心贡献** | 提出 GSAT——基于信息瓶颈的内禀可解释模型，**首次同时实现**高可解释性、强泛化性和无精度妥协 |
| **理论保证** | 在一定假设下，GSAT 选择的子图**可证明不包含虚假相关模式** |

#### 核心思路

```
完整图 G
    │
    ├─ 注意力权重 αᵢ (每条边的"重要性")
    │       │
    │       ├─ 注入随机性（高噪声 → 阻断信息）
    │       └─ 学习降低随机性（对关键边 → 保留信息）
    │
    ▼
提取低噪声子图 → 分类器
    │
    ▼
信息瓶颈目标：max I(ŷ; G_sub) - β·I(G; G_sub)
                ↑ 预测精度            ↑ 子图稀疏度
```

1. **随机注意力注入**：对边注意力加噪声——任务无关的边保持高噪声（信息被阻断），任务相关的边学习降低噪声
2. **信息瓶颈优化**：最大化子图与标签的互信息，同时约束子图与完整图的互信息
3. **训练后解释**：低噪声边构成的子图 = 模型的"推理依据"

#### 与本项目的对比分析

##### 相似之处

| 维度 | GSAT | 本项目 |
|------|------|--------|
| **核心目标** | 从图中选出任务相关子图来做分类 | 从图中揭示任务相关证据来做分类 |
| **信息论基础** | 信息瓶颈（IB） | 可纳入 IB 做价值函数（M4 阶段） |
| **稀疏性** | β 参数控制子图稀疏度 | 预算 B 控制揭示量——都追求"用最少信息做最好预测" |

##### 关键差异

| 维度 | GSAT | 本项目 |
|------|------|--------|
| **图可见性** | 完整图 G 始终可见 | 逐步揭示 G_<b → G_b（根本差异） |
| **选择机制** | 连续随机注意力（软选择，所有边有权重） | 离散揭示动作（硬选择，揭示=完全获得信息） |
| **预算模型** | 信息瓶颈 β 控制稀疏度（连续软约束） | 显式整数预算 B + 原子成本（离散硬约束） |
| **优化方式** | 互信息上下界优化 | 策略优化（启发式 → 模仿学习 → 端到端） |
| **核心隐喻** | 注意力筛选（滤除噪声边） | 图阅读——"翻开一页"知道一页的内容 |

> **启示**：GSAT 的随机注意力 + 信息瓶颈框架可以直接适配为我们的"揭示动作选择器"——将注意力权重映射为"下一步揭示哪个节点"的概率分布。其理论保证（消除虚假相关性）是 M5 阶段学习型策略的重要设计参考。

### 论文 3：CAL — 因果注意力实现可解释可泛化的图分类

| 维度 | 内容 |
|------|------|
| **论文名称** | Causal Attention for Interpretable and Generalizable Graph Classification |
| **作者** | Yongduo Sui, Xiang Wang, Jiancan Wu, Min Lin, Xiangnan He, Tat-Seng Chua |
| **发表** | **KDD 2022** |
| **期刊等级** | **CCF-A**（数据挖掘顶级会议） |
| **arXiv** | [2112.15089](https://arxiv.org/abs/2112.15089) |

#### 摘要

在图分类中，基于注意力和池化的 GNN 通过"学习关注"范式——最大化关注图与真实标签之间的互信息——来提取关键特征。然而，该范式使 GNN 分类器不加区分地吸收输入特征与标签之间的所有统计相关性，而不区分特征的因果效应与非因果效应。这使得模型容易被捷径特征所迷惑。本文提出因果注意力学习（CAL）策略：使用注意力模块分别估计因果特征和捷径特征，并通过参数化后门调整使模型学会不受捷径分布变化影响的稳定因果映射。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 标准注意力 GNN 的"学习关注"范式不区分因果与虚假相关，捷径特征作为混杂因子破坏 OOD 泛化 |
| **核心贡献** | 首次将**后门调整（backdoor adjustment）**引入 GNN 注意力机制，通过分解因果/捷径特征并参数化混杂控制实现去混杂化 |

#### 核心思路

```
输入图 G
    │
    ├─ 注意力估计因果特征 C
    ├─ 注意力估计捷径特征 S（混杂因子）
    │
    ▼
P(Y|do(C)) = Σ_s P(Y|C, S=s) · P(S=s)
              ↑ 后门调整公式
              
对每个可能的捷径特征 s，计算 C→Y 的条件概率
然后按 P(S=s) 加权求和 → 消除 S 的混杂效应
```

1. **特征分解**：注意力模块分别估计因果子图 C 和捷径/混杂子图 S
2. **后门调整**：参数化 do-calculus 的后门调整公式，计算 P(Y|do(C))——"如果主动设置 C，Y 会如何"
3. **去混杂化**：通过遍历所有可能的 S 来打破 C-S 之间的虚假关联

#### 与本项目的对比分析

##### 相似之处

| 维度 | CAL | 本项目 |
|------|-----|--------|
| **选择性关注** | 从完整图中选择因果子图 | 从图中逐步选择揭示证据 |
| **区分因果与虚假** | 显式分离因果特征与捷径特征 | 期望策略学到任务相关而非噪声区域 |
| **下游任务** | 图分类 | 图分类 |

##### 关键差异

| 维度 | CAL | 本项目 |
|------|-----|--------|
| **图可见性** | 完整图可见 | 逐步揭示（根本差异） |
| **因果框架** | 显式因果推断（后门调整 do-calculus） | 不直接涉及因果推断（策略优化视角） |
| **核心目标** | 去混杂——让模型关注因果特征而非捷径 | 预算约束——在有限预算内最优揭示证据 |
| **选择方式** | 软注意力（连续权重） | 硬揭示（离散动作） |
| **时序性** | 单步选择 | 多步顺序选择 |

> **启示**：CAL 的因果框架为我们提供了"什么是好的揭示"的理论锚点——如果 M4/M5 阶段需要设计 oracle 策略或教师策略，CAL 的因果特征分解可作为 oracle 的子图标注方法。

### 论文 4：GREA — 基于环境增强的图理性化

| 维度 | 内容 |
|------|------|
| **论文名称** | Graph Rationalization with Environment-based Augmentations |
| **作者** | Gang Liu, Tong Zhao, Jiaxin Xu, Tengfei Luo, Meng Jiang |
| **发表** | **KDD 2022** |
| **期刊等级** | **CCF-A**（数据挖掘顶级会议） |
| **arXiv** | [2206.02886](https://arxiv.org/abs/2206.02886) |

#### 摘要

理性被定义为最能解释或支持机器学习模型预测的输入特征子集。理性识别已在视觉和语言数据上改善了神经网络的泛化性和可解释性。在图应用中（如分子和聚合物性质预测），识别代表性子图结构（图理性）对 GNN 性能至关重要。现有的图池化和分布干预方法受限于缺乏学习识别最优图理性的示例。本文引入一种新的增强操作——**环境替换**（environment replacement），自动创建虚拟数据示例以改善理性识别，并提出一个高效框架在潜在空间中执行理性-环境分离和表示学习，避免显式图编解码的高复杂度。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 图理性化方法面临**训练样本不足**的问题——缺乏足够多样化的环境来学习区分理性与环境 |
| **核心贡献** | 提出环境替换增强——自动生成虚拟环境样本，扩大理性学习的训练分布；全潜在空间操作保证效率 |

#### 核心思路

```
原始图 G
    │
    ├─ 理性提取器 → 理性子图 R ╮
    │                          ├─ 潜在空间拼接
    └─ 环境替换增强 → 虚拟环境 E ╯
                    │
                    ▼
              分类器(R ⊕ E) → 预测
              ↑ 理性不变，环境可变 → 学习因果理性
```

1. **环境替换**：保持理性子图不变，替换环境子图（通过采样不同图的非理性部分），生成增强样本
2. **潜在空间操作**：理性-环境分离和重组在潜在空间完成，避免显式图结构编解码
3. **不变性学习**：理性子图在不同环境中保持预测稳定 → 学到因果理性

#### 与本项目的对比分析

##### 相似之处

| 维度 | GREA | 本项目 |
|------|------|--------|
| **核心操作** | 从图中分离出关键子图（理性） | 从图中逐步揭示关键证据 |
| **不变性思想** | 理性子图跨环境不变 | （隐含）关键证据应跨图具有泛化性 |
| **数据增强** | 环境替换生成增强样本 | （可借鉴）轨迹数据增强 |

##### 关键差异

| 维度 | GREA | 本项目 |
|------|------|--------|
| **图可见性** | 完整图可见 | G₀ = (V, ∅, ∅)，逐步揭示（根本差异） |
| **增强策略** | 环境替换（跨图拼接非理性部分） | 无需增强——揭示过程本身就是"信息获取" |
| **选择目标** | 完整图中划分理性 vs 环境 | 从空图 G₀ 逐步揭示证据 |
| **预算** | 无预算约束 | 显式预算 B + 原子成本 |
| **效率关注** | 潜在空间操作避免编解码 | 动作空间离散化减少搜索复杂度 |

> **启示**：GREA 的"环境替换"思路可以转化为我们项目的**数据增强方案**——在训练轨迹时，通过替换已揭示子图之外的部分来生成更多样的"阅读场景"。

### 论文 5：CIGA — 为图的分布外泛化学习因果不变表示

| 维度 | 内容 |
|------|------|
| **论文名称** | Learning Causally Invariant Representations for Out-of-Distribution Generalization on Graphs |
| **作者** | Yongqiang Chen, Yonggang Zhang, Yatao Bian, Han Yang, Kaili Ma 等 |
| **发表** | **NeurIPS 2022** |
| **期刊等级** | **CCF-A**（人工智能顶级会议） |
| **arXiv** | [2202.05441](https://arxiv.org/abs/2202.05441) |

#### 摘要

尽管不变性原理在欧氏数据（如图像）的 OOD 泛化上取得成功，但图数据的研究仍然有限。与图像不同，图的复杂特性给应用不变性原理带来了独特挑战：图上的分布偏移可以以属性和结构等多种形式出现，使不变性的识别变得困难；此外，欧氏数据 OOD 方法通常需要的领域/环境标签在图数据上获取成本极高。本文提出因果启发的不变图学习（CIGA）框架：利用因果模型刻画图上的分布偏移，得出 OOD 泛化可通过关注包含标签因果信息最多的子图来实现的结论；提出信息论目标以提取最大程度保留类别内不变信息的期望子图。在 16 个数据集上验证了 CIGA 的 OOD 泛化优势。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 图上的分布偏移形式多样（结构+属性），环境标签获取困难，不变性原理难以直接应用 |
| **核心贡献** | 因果建模图分布偏移 → 证明关注因果子图可实现 OOD 泛化；信息论目标无需环境标签即可提取不变子图 |

#### 核心思路

```
图的结构因果模型（SCM）：
    C（因果子图） → Y（标签）
    S（虚假子图） → Y（也可预测，但不稳定）
    C ← → S（在训练分布中相关）

关键结论：
    只需关注 C（因果子图），模型对 S 的分布偏移免疫

信息论目标：
    max I(G_sub; Y)  ← 最大化子图与标签的互信息
    s.t. G_sub 跨类别具有不变性
```

1. **结构因果模型**：将图分解为因果子图 C 和虚假子图 S，建模分布偏移
2. **理论保证**：证明只使用 C 的预测器在所有分布偏移下都是不变的
3. **无环境标签**：通过最大化类内互信息 + 约束类间差异，隐式地提取因果子图

#### 与本项目的对比分析

##### 相似之处

| 维度 | CIGA | 本项目 |
|------|------|--------|
| **核心目标** | 提取因果子图 → 分类 | 揭示关键证据 → 分类 |
| **环境无关性** | 不需要显式环境标签 | 不需要环境标签 |
| **理论基础** | 信息论（最大化 I(G_sub; Y)） | 可纳入信息论价值函数 |

##### 关键差异

| 维度 | CIGA | 本项目 |
|------|------|--------|
| **图可见性** | 完整图 G 始终可见 | 逐步揭示（根本差异） |
| **理论基础** | 结构因果模型（SCM） + 不变性原理 | 马尔可夫决策过程（MDP） + 策略优化 |
| **预算** | 无预算约束 | 显式预算 B |
| **选择粒度** | 子图级（粗粒度） | 原子动作 → 复合揭示（细粒度） |
| **核心隐喻** | 因果不变性（科学发现视角） | 阅读行为（agent 交互视角） |

> **启示**：CIGA 的理论框架（因果子图 → 分布不变预测）为我们的**oracle 策略设计**提供了理论基础——如果已知因果子图，最优阅读策略应优先揭示因果子图中的节点/边。

## 类别二：图信息瓶颈

### 论文 6：GIB — 图信息瓶颈

| 维度 | 内容 |
|------|------|
| **论文名称** | Graph Information Bottleneck |
| **作者** | Tailin Wu, Hongyu Ren, Pan Li, Jure Leskovec |
| **发表** | **NeurIPS 2020** |
| **期刊等级** | **CCF-A**（人工智能顶级会议） |
| **arXiv** | [2010.12811](https://arxiv.org/abs/2010.12811) |

#### 摘要

图结构数据的表示学习具有挑战性，因为图结构和节点特征都携带重要信息。GNN 提供了融合网络结构和节点特征的表现力方式，但容易受到对抗攻击。本文引入图信息瓶颈（GIB）——一种信息论原理，可最优地平衡图结构数据学习表示的**表现力**和**鲁棒性**。GIB 继承了通用信息瓶颈（IB），目标是通过最大化表示与目标之间的互信息、同时约束表示与输入数据之间的互信息，来学习任务的最小充分表示。与通用 IB 不同的是，GIB 同时正则化结构信息和特征信息。本文设计了两种结构正则化的采样算法，并实例化为 GIB-Cat 和 GIB-Bern 两个模型。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | GNN 在对抗攻击下脆弱，缺乏同时平衡表现力与鲁棒性的信息论框架 |
| **核心贡献** | 首次将信息瓶颈扩展到图数据，**同时正则化结构与特征信息**；设计两种采样算法（GIB-Cat、GIB-Bern）实现该原理 |

#### 核心思路

```
经典信息瓶颈（IB）：
    max I(Z; Y) - β·I(Z; X)
    学到的表示 Z 应该：①能预测 Y  ②不记住太多 X 的细节

图信息瓶颈（GIB）：
    max I(Z; Y) - β·I(Z; G)    ← G 包含结构 A + 特征 X
    
    正则化：同时约束 Z 与图结构的信息 + Z 与节点特征的信息
    
    采样实现：
    GIB-Cat：分类采样图组件
    GIB-Bern：伯努利采样图组件
```

1. **信息瓶颈扩展**：将 IB 的输入从向量 X 扩展为图 G = (A, X)
2. **双重正则化**：同时约束表示 Z 与结构 A 的 MI + Z 与特征 X 的 MI
3. **采样实例化**：通过随机采样图组件（边/节点）来估计和优化互信息上下界

#### 与本项目的对比分析

##### 相似之处

| 维度 | GIB | 本项目 |
|------|-----|--------|
| **信息论目标** | 最小充分表示：max I(Z;Y) - β·I(Z;G) | 预算约束下的最大信息揭示 |
| **压缩需求** | 约束 I(Z;G) 实现压缩 | 预算 B 限制可观测信息量 |
| **稀疏学习** | 采样算法选择图组件 | 揭示动作选择图组件 |

##### 关键差异

| 维度 | GIB | 本项目 |
|------|-----|--------|
| **图可见性** | 完整图 G 始终可见 | 逐步揭示（根本差异） |
| **优化目标** | 表示 Z 的最小充分性（表示学习） | 揭示策略 π 的最优性（决策学习） |
| **选择粒度** | 软采样（所有边有权重，连续优化） | 硬揭示（离散选择，组合优化） |
| **鲁棒性焦点** | 对抗鲁棒性 | 预算效率 |
| **信息流动** | 采样用于训练/正则化 | 揭示是系统行为的核心（类比阅读） |

> **启示**：GIB 的信息瓶颈公式可以直接转化为我们项目的价值函数——每次揭示动作的"信息增益"可以近似为 ΔI(ŷ; G_b | G_{<b})。这在 M4 阶段的轨迹评分中可以作为核心指标。

### 论文 7：Policy-Learn — 通过学习有效选择策略实现高效子图 GNN

| 维度 | 内容 |
|------|------|
| **论文名称** | Efficient Subgraph GNNs by Learning Effective Selection Policies |
| **作者** | Beatrice Bevilacqua, Moshe Eliasof, Eli Meirom, Bruno Ribeiro, Haggai Maron |
| **发表** | **ICLR 2024** |
| **期刊等级** | **CCF-A**（国际表征学习顶级会议） |
| **arXiv** | [2310.20082](https://arxiv.org/abs/2310.20082) |

> 详细精读报告见 `policy-learn-deep-read.md`。此处仅做高层对比。

#### 核心对比

##### 相似之处

| 维度 | Policy-Learn | 本项目 |
|------|-------------|--------|
| **核心思想** | 从 n 个候选中迭代选择 T 个 | 从图 G 的节点/边中迭代揭示 B 个 |
| **选择方式** | 学习型策略（DS-GNN + Gumbel-Softmax） | 启发式 → 模仿学习 → 端到端策略 |
| **预算约束** | 固定子图数 T | 固定成本预算 B（原子成本可加） |
| **下游任务** | 图分类/回归 | 图分类 |
| **顺序性** | 顺序采样（每步依赖前步选择） | 顺序揭示（每步依赖前步观测） |
| **训练** | 端到端（Gumbel-Softmax 回传梯度） | 教师-学生蒸馏 → 端到端（M4/M5） |

##### 关键差异

| 维度 | Policy-Learn | 本项目 |
|------|-------------|--------|
| **图可见性** | 完整图 G 始终可见（只决定选哪个子图） | G₀ = (V, ∅, ∅)，逐步揭示（根本差异） |
| **候选池** | 固定——每个节点预生成一个子图 | 无预生成——在原始图上"探险" |
| **初始状态** | 已有完整图 + n 个候选子图 | G₀ 仅知节点 ID，无边无特征 |
| **选择粒度** | 子图级（粗粒度） | 原子级 → 复合动作（细粒度） |
| **预算模型** | 固定子图数 T（无成本差异） | 原子成本可加（c_n, c_e, c_nf, c_ef 有差异） |
| **研究焦点** | 子图 GNN 的表达能力与效率 | 证据获取——"在预算内学会往哪里看" |
| **核心隐喻** | 子图选择（菜单点菜） | 图阅读（黑屋探险） |

> **本质差异**：Policy-Learn 是"从菜单中点菜"——完整菜单在手，预算内选最营养的。本项目是"在黑屋里探险"——只有目录编号，摸到什么才知道什么。这个差异是论文定位的核心锚点。

### 论文 8：CwCF — 具有代价特征的分层深度集合分类

| 维度 | 内容 |
|------|------|
| **论文名称** | Classification with Costly Features in Hierarchical Deep Sets |
| **作者** | Jaromír Janisch, Tomáš Pevný, Viliam Lisý |
| **发表** | ICML 2021 Workshop / **Machine Learning Journal**（Springer） |
| **期刊等级** | **SCI**（机器学习权威期刊） |
| **arXiv** | [1911.08756](https://arxiv.org/abs/1911.08756) |

#### 摘要

具有代价特征的分类（CwCF）将特征成本纳入优化目标：对每个样本，按顺序获取其特征以最大化准确率同时最小化特征获取成本。然而，现有方法仅能处理固定长度向量数据，但实际数据通常具有丰富的层次结构（XML/JSON/嵌套对象列表）。本文将基于深度强化学习的 CwCF 算法扩展为分层深度集合和分层 softmax，使其可直接处理结构化数据。扩展方法对特征获取有更精细的控制，在 7 个数据集上表现优越，并应用于恶意网络域分类。

#### 核心问题与贡献

| 维度 | 内容 |
|------|------|
| **核心问题** | 预算约束下顺序获取特征的分类问题——但已有方法只能处理固定向量 |
| **核心贡献** | 提出分层深度集合方法处理结构化特征（树形/嵌套），更精细的特征级预算控制 |

#### 核心思路

```
每次决策（DRL agent）：
    当前已获取特征 → 状态 s_t
    ├─ 下一步获取哪个特征？→ 动作 a_t
    └─ 是否停止获取并预测？→ 停止动作
    奖励 = 分类正确 - λ·特征总代价
```

1. **MDP 建模**：状态=已获取特征集合，动作=获取下一个特征或停止
2. **深度 Q 网络**：学习 Q(s, a) → 选择期望净收益最高的动作
3. **分层扩展**：处理树形结构的特征（如 JSON/XML），在树的每层做出获取决策

#### 与本项目的对比分析

##### 相似之处

| 维度 | CwCF | 本项目 |
|------|------|--------|
| **核心范式** | 预算约束 + 顺序特征获取 + 分类 | 预算约束 + 顺序揭示 + 分类 |
| **决策建模** | MDP（状态=已获取特征，动作=获取/停止） | MDP（状态=观测图 G_b，动作=揭示动作） |
| **代价模型** | 每个特征有获取代价 | 每个原子动作有揭示成本 |
| **停止条件** | 预算耗尽或 agent 主动停止 | 预算耗尽或策略输出 ∅ 终止 |
| **优化方法** | 深度 Q 网络（DQN） | 启发式 → 模仿学习 → RL/端到端 |

##### 关键差异

| 维度 | CwCF | 本项目 |
|------|------|--------|
| **数据模态** | 表格特征（向量/JSON 树） | 图结构（节点 + 边 + 特征）——更复杂的依赖关系 |
| **决策空间** | 获取哪个特征/子树 | 揭示哪个节点/边/邻域/游走 |
| **信息依赖** | 特征之间独立或树形依赖 | 图结构——揭示一个节点暴露其邻居关联 |
| **状态表示** | 已获取特征的集合 | 部分观测图 G_<b（含拓扑信息） |
| **代价粒度** | 异质特征代价 | 统一原子成本（c_n=1, c_e=1, c_nf=2, c_ef=2） |

> **启示**：CwCF 是**最接近的跨域方法论类比**——它的 MDP 形式化（状态/动作/奖励）可以直接映射到我们的图揭示场景，但图结构引入了节点间的空间依赖性，使决策空间更复杂。
